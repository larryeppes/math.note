## 一、选择题（每小题 5 分，共 30 分）

**1.** 双曲线 $\dfrac{x^2}{a^2} - \dfrac{y^2}{b^2} = 1$ 的左、右准线 $l_1$、$l_2$ 将线段 $F_1F_2$ 三等分（其中 $F_1$、$F_2$ 分别为双曲线的左、右焦点），则该双曲线的离心率 $e$ 等于（　　）.

A、$\dfrac{\sqrt{6}}{2}$　　B、$\sqrt{3}$　　C、$\dfrac{3\sqrt{3}}{2}$　　D、$2\sqrt{3}$

**解** 由题意得 $2c = 3 \times \dfrac{2a^2}{c}$，解得 $e = \sqrt{3}$. 故答案选 B.

**2.** 已知三次函数 $f(x) = ax^3 + bx^2 + cx + d$，$(a, b, c, d \in R)$.

命题 $p$：$y = f(x)$ 是 $R$ 上的单调函数；

命题 $q$：$y = f(x)$ 的图像与 $x$ 轴恰有一个交点.

则 $p$ 是 $q$ 的（　　）

A、充分但不必要条件　　B、必要但不充分条件

C、充要条件　　D、既不充分也不必要条件

**解** 选 A.

**3.** 甲、乙、丙三人一起玩"剪刀、石头、布"的游戏. 每一局甲、乙、丙同时出"剪刀、石头、布"中的一种手势，且是相互独立的. 设在一局中甲赢的人数为 $\xi$，则随机变量 $\xi$ 的数学期望 $E\xi$ 的值为（　　）

A、$\dfrac{1}{3}$　　B、$\dfrac{4}{9}$　　C、$\dfrac{2}{3}$　　D、$1$

**解** $P(\xi = 0) = \dfrac{3 \times 4}{27} = \dfrac{4}{9}$，$P(\xi = 1) = \dfrac{3 \times 4}{27} = \dfrac{4}{9}$，$P(\xi = 2) = \dfrac{3 \times 1}{27} = \dfrac{1}{9}$，

于是 $E\xi = \dfrac{4}{9} \times 0 + \dfrac{4}{9} \times 1 + \dfrac{1}{9} \times 2 = \dfrac{2}{3}$. 故答案选 C.

**4.** 函数 $f(x) = \sqrt{x - 5} + \sqrt{24 - 3x}$ 的最大值为（　　）

A、$\sqrt{3}$　　B、$3$　　C、$2\sqrt{3}$　　D、$3\sqrt{3}$

**解** 法一：$f(x)$ 的定义域为 $5 \le x \le 8$.

由 $f'(x) = \dfrac{1}{2\sqrt{x - 5}} + \dfrac{-3}{2\sqrt{24 - 3x}} = \dfrac{\sqrt{24 - 3x} - 3\sqrt{x - 5}}{2\sqrt{x - 5} \cdot \sqrt{24 - 3x}} = 0$，解得 $x = \dfrac{23}{4}$.

因为 $f(5) = 3$，$f\left(\dfrac{23}{4}\right) = 2\sqrt{3}$，$f(8) = \sqrt{3}$，于是 $f(x)_{\max} = f\left(\dfrac{23}{4}\right) = 2\sqrt{3}$.

故答案选 C.

法二：$f(x)$ 的定义域为 $5 \le x \le 8$，

$$f^2(x) = \left(1 \cdot \sqrt{x - 5} + \sqrt{3} \cdot \sqrt{8 - x}\right)^2 \le (1 + 3)(x - 5 + 8 - x) = 12$$

当且仅当 $\dfrac{\sqrt{x - 5}}{1} = \dfrac{\sqrt{8 - x}}{\sqrt{3}}$，即 $x = \dfrac{23}{4}$ 时，$f(x)$ 取到最大值 $2\sqrt{3}$. 故答案选 C.

**5.** 如图，边长为 2 的正方形 $ABCD$ 和正方形 $ABEF$ 所在的面成 $60°$ 角，$M$、$N$ 分别是线段 $AC$ 和 $BF$ 上的点，且 $AM = FN$，则线段 $MN$ 的长的取值范围是

> 【图：边长为 2 的正方形 $ABCD$ 与正方形 $ABEF$ 沿公共棱 $AB$ 展开成 $60°$ 二面角的立体图，各顶点标注 $A$、$B$、$C$、$D$、$E$、$F$，并标出 $AC$ 上的点 $M$ 与 $BF$ 上的点 $N$】

A、$\left[\dfrac{1}{2}, 2\right]$　　B、$[1, 2]$　　C、$[\sqrt{2}, 2]$　　D、$[\sqrt{3}, 2]$

**解** 过点 $M$ 作 $MH \parallel BC$ 交 $AB$ 于 $H$，则 $\dfrac{AM}{AC} = \dfrac{AH}{AB}$.

> 【图：同一立体图的另一视角，标出 $AC$ 上的点 $M$、$BF$ 上的点 $N$ 及 $AB$ 上的辅助点 $H$，并画出辅助线 $MH$、$NH$】

又 $AM = FN$，$AC = FB$，$\therefore \dfrac{FN}{FB} = \dfrac{AH}{AB}$，$\therefore NH \parallel AF$，

$\therefore NH \perp AB$，$MH \perp AB$. $\therefore \angle MHN = 60°$.

设 $AH = x\ (0 \le x \le 2)$，则 $MH = x$，$NH = 2 - x$.

$$\therefore MN = \sqrt{x^2 + (2 - x)^2 - 2x(2 - x)\cos 60°} = \sqrt{3x^2 - 6x + 4} = \sqrt{3(x - 1)^2 + 1}$$

$\therefore 1 \le MN \le 2$. 选答案选 B. [注：原文如此，疑为"故答案选 B"]

**6.** 设数列 $\{a_n\}$ 为等差数列，数列 $\{b_n\}$ 满足：$b_1 = a_1$，$b_2 = a_2 + a_3$，$b_3 = a_4 + a_5 + a_6$，……，若 $\lim\limits_{n \to \infty} \dfrac{b_n}{n^3} = 2$，则数列 $\{a_n\}$ 的公差 $d$ 为（　　）

A、$\dfrac{1}{2}$　　B、$1$　　C、$2$　　D、$4$

**解** $b_n = a_{\frac{n(n-1)}{2}+1} + a_{\frac{n(n-1)}{2}+2} + \cdots + a_{\frac{n(n-1)}{2}+n} = \dfrac{n}{2}\left[a_{\frac{n(n-1)}{2}+1} + a_{\frac{n(n-1)}{2}+n}\right]$

$$= \frac{n}{2}\left[a_1 + \left(\frac{n(n-1)}{2} + 1 - 1\right)d + a_1 + \left(\frac{n(n-1)}{2} + n - 1\right)d\right] = \frac{n}{2}(2a_1 - d + n^2 d)$$

于是 $\lim\limits_{n \to \infty} \dfrac{b_n}{n^3} = \lim\limits_{n \to \infty} \dfrac{1}{2}\left(\dfrac{2a_1 - d}{n^2} + d\right) = \dfrac{d}{2} = 2$，解得 $d = 4$，故答案选 D.

## 二、填空题（每小题 5 分，共 30 分）

**7.** 已知实数 $x$ 满足 $|2x + 1| + |2x - 5| = 6$，则 $x$ 的取值范围是________.

**解** 因为 $|2x + 1| + |2x - 5| \ge |(2x + 1) + (5 - 2x)| = 6$，

等号成立当且仅当 $(2x + 1)(2x - 5) \le 0$，即 $-\dfrac{1}{2} \le x \le \dfrac{5}{2}$. 故答案填 $\left[-\dfrac{1}{2}, \dfrac{5}{2}\right]$.

**8.** 设平面内的两个非零向量 $\vec{a}$ 与 $\vec{b}$ 相互垂直，且 $|\vec{b}| = 1$，则使得向量 $\vec{a} + m\vec{b}$ 与 $\vec{a} + (1 - m)\vec{b}$ 互相垂直的所有实数 $m$ 之和为_______.

**解** 由于 $0 = (\vec{a} + m\vec{b}) \cdot (\vec{a} + (1 - m)\vec{b}) = \vec{a}^2 + \vec{a} \cdot \vec{b} + m(1 - m)\vec{b}^2 = |\vec{a}|^2 + m(1 - m)$，

即 $m^2 - m - |\vec{a}|^2 = 0$，

所以由根与系数的关系知符合条件所有实数 $m$ 之和为 1. 故答案填 1.

**9.** 记实数等比数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，若 $S_{10} = 10$，$S_{30} = 70$，则 $S_{40} = $_______.

**解** 记 $b_1 = S_{10}$，$b_2 = S_{20} - S_{10}$，$b_3 = S_{30} - S_{20}$，$b_4 = S_{40} - S_{30}$.

设 $q$ 为 $\{a_n\}$ 的公比. 则 $b_1, b_2, b_3, b_4$ 构成以 $r = q^{10}$ 为公比的等比数列.

于是 $70 = S_{30} = b_1 + b_2 + b_3 = b_1(1 + r + r^2) = 10(1 + r + r^2)$

即 $r^2 + r - 6 = 0$，解得 $r = 2$ 或 $r = -3$（舍去）.

故 $S_{40} = 10(1 + r + r^2 + r^3) = 150$. 故答案填 150.

**10.** 设 $x$ 为实数，定义 $[x]$ 为不小于 $x$ 的最小整数，例如 $[\pi] = 4$，$[-\pi] = -3$. 关于实数 $x$ 的方程 $\left[3x + 1\right] = 2x - \dfrac{1}{2}$ 的全部实根之和等于________.

**解** 设 $2x - \dfrac{1}{2} = k \in Z$，则 $x = \dfrac{2k + 1}{4}$，$3x + 1 = k + 1 + \dfrac{2k + 3}{4}$，于是原方程等价于 $\left\lceil \dfrac{2k + 3}{4} \right\rceil = -1$，

即 $-2 < \dfrac{2k + 3}{4} \le -1$，从而 $-\dfrac{11}{2} < k \le -\dfrac{7}{2}$，即 $k = -5$ 或 $-4$.

相应的 $x$ 为 $-\dfrac{9}{4}$，$-\dfrac{7}{4}$. 于是所有实根之和为 $-4$. 故答案填 $-4$.

**11.** 已知 $(1 + \sqrt{3})^n = a_n + b_n\sqrt{3}$，其中 $a_n, b_n$ 为整数，则 $\lim\limits_{n \to \infty} \dfrac{a_n}{b_n} = $_______.

**解** 由条件 $(1 + \sqrt{3})^n = a_n + b_n\sqrt{3}$ 知 $(1 - \sqrt{3})^n = a_n - b_n\sqrt{3}$，

于是 $a_n = \dfrac{1}{2}\left[(1 + \sqrt{3})^n + (1 - \sqrt{3})^n\right]$，$b_n = \dfrac{1}{2\sqrt{3}}\left[(1 + \sqrt{3})^n - (1 - \sqrt{3})^n\right]$，

故 $\lim\limits_{n \to \infty} \dfrac{a_n}{b_n} = \lim\limits_{n \to \infty} \sqrt{3} \times \dfrac{(1 + \sqrt{3})^n + (1 - \sqrt{3})^n}{(1 + \sqrt{3})^n - (1 - \sqrt{3})^n} = \lim\limits_{n \to \infty} \sqrt{3} \times \dfrac{1 + \left(\dfrac{1 - \sqrt{3}}{1 + \sqrt{3}}\right)^n}{1 - \left(\dfrac{1 - \sqrt{3}}{1 + \sqrt{3}}\right)^n} = \sqrt{3}$.

故答案填 $\sqrt{3}$.

**12.** 已知三棱锥 $S$-$ABC$ 的底面是以 $AB$ 为斜边的等腰直角三角形，且 $SA = SB = SC = AB = 2$，设 $S$、$A$、$B$、$C$ 四点均在以 $O$ 为球心的某个球面上，则点 $O$ 到平面 $ABC$ 的距离为_________.

> 【图：三棱锥 $S$-$ABC$ 的立体图，$S$ 在上方，底面为 $\triangle ABC$，内部以虚线标出球心 $O$、$AB$ 的中点 $H$ 及相关连线】

**解** 如图，因为 $SA = SB = SC$，所以 $S$ 在平面 $ABC$ 上的射影是 $\triangle ABC$ 的外心，即 $AB$ 的中点 $H$. 同理 $O$ 点在平面 $ABC$ 上的射影也是 $\triangle ABC$ 的外心 $H$，即在等边 $\triangle SAB$ 中，求 $OH$ 的长，其中 $OA = OB = OS$.

显然，$OH = \dfrac{1}{3}SH = \dfrac{1}{3} \times 2 \times \dfrac{\sqrt{3}}{2} = \dfrac{\sqrt{3}}{3}$. 故答案填 $\dfrac{\sqrt{3}}{3}$.

## 三、解答题（每小题 20 分，共 80 分）

**13.** 已知 $m > 0$，若函数 $f(x) = x + \sqrt{100 - mx}$ 的最大值为 $g(m)$，求 $g(m)$ 的最小值.

**解** 令 $t = \sqrt{100 - mx}$，则 $x = \dfrac{100 - t^2}{m}$. （5 分）

$$\because y = \frac{100 - t^2}{m} + t = -\frac{1}{m}\left(t - \frac{m}{2}\right)^2 + \frac{100}{m} + \frac{m}{4}$$

$\therefore$ 当 $t = \dfrac{m}{2}$ 时，$y$ 有最大值 $\dfrac{100}{m} + \dfrac{m}{4}$，即 $g(m) = \dfrac{100}{m} + \dfrac{m}{4}$. （10 分）

$$\therefore g(m) = \frac{100}{m} + \frac{m}{4} \ge 2\sqrt{\frac{100}{m} \times \frac{m}{4}} = 10$$ （15 分）

等号当且仅当 $m = 20$ 时成立.

$\therefore$ 当 $m = 20$ 时，$g(m)$ 有最小值 10. （20 分）

**14.** 已知函数 $f(x) = 2(\sin^4 x + \cos^4 x) + m(\sin x + \cos x)^4$ 在 $x \in \left[0, \dfrac{\pi}{2}\right]$ 有最大值 5，求实数 $m$ 的值.

**解** $f(x) = 2(\sin^2 x + \cos^2 x)^2 - 4\sin^2 x\cos^2 x + m(\sin x + \cos x)^4$

$$= 2 - (2\sin x\cos x)^2 + m(\sin x + \cos x)^4$$ （5 分）

令 $t = \sin x + \cos x = \sqrt{2}\sin\left(x + \dfrac{\pi}{4}\right) \in [1, \sqrt{2}]$，

则 $2\sin x\cos x = t^2 - 1$，从而 $f(x) = 2 - (t^2 - 1)^2 + mt^4 = (m - 1)t^4 + 2t^2 + 1$ （10 分）

令 $u = t^2 \in [1, 2]$，由题意知 $g(u) = (m - 1)u^2 + 2u + 1$ 在 $u \in [1, 2]$ 有最大值 5.

当 $m - 1 = 0$ 时，$g(u) = 2u + 1$ 在 $u = 2$ 时有最大值 5，故 $m = 1$ 符合条件； （15 分）

当 $m - 1 > 0$ 时，$g(u)_{\max} \ge g(2) > 2 \times 2 + 1 = 5$，矛盾！

当 $m - 1 < 0$ 时，$g(u) < 2u + 1 \le 5$，矛盾！

综上所述，所求的实数 $m = 1$. （20 分）

**15.** 抛物线 $y = x^2$ 与过点 $P(-1, -1)$ 的直线 $l$ 交于 $P_1$、$P_2$ 两点.

（Ⅰ）求直线 $l$ 的斜率 $k$ 的取值范围；

（Ⅱ）求在线段 $P_1P_2$ 上满足条件 $\dfrac{1}{PP_1} + \dfrac{1}{PP_2} = \dfrac{2}{PQ}$ 的点 $Q$ 的轨迹方程.

**解** （Ⅰ）直线 $l$ 的方程为 $y + 1 = k(x + 1)$，与抛物线方程 $y = x^2$ 联立

得 $\begin{cases} y = x^2 \\ y + 1 = k(x + 1) \end{cases}$，消去 $y$ 得 $x^2 = k(x + 1) - 1$，即 $x^2 - kx - (k - 1) = 0$，

由 $\Delta = (-k)^2 + 4(k - 1) > 0$，解得 $k > -2 + 2\sqrt{2}$ 或 $k < -2 - 2\sqrt{2}$. （5 分）

（Ⅱ）设 $Q$ 点坐标为 $(x, y)$，$P_1$ 点坐标为 $(x_1, y_1)$，$P_2$ 点坐标为 $(x_2, y_2)$，

则 $x_1 + x_2 = k$，$x_1 \cdot x_2 = -(k - 1)$，

又 $P_1$、$P_2$、$Q$ 都在直线 $l$ 上，所以有 $y + 1 = k(x + 1)$，$y_1 + 1 = k(x_1 + 1)$，$y_2 + 1 = k(x_2 + 1)$，

由 $\dfrac{1}{PP_1} + \dfrac{1}{PP_2} = \dfrac{2}{PQ}$ 得

$$\frac{1}{\sqrt{(x_1 + 1)^2 + (y_1 + 1)^2}} + \frac{1}{\sqrt{(x_2 + 1)^2 + (y_2 + 1)^2}} = \frac{2}{\sqrt{(x + 1)^2 + (y + 1)^2}}$$

化简得 $\dfrac{1}{|x_1 + 1|} + \dfrac{1}{|x_2 + 1|} = \dfrac{2}{|x + 1|}$ （10 分）

又 $(x_1 + 1)(x_2 + 1) = x_1x_2 + x_1 + x_2 + 1 = -(k - 1) + k + 1 = 2 > 0$，点 $Q$ 在线段 $P_1P_2$ 上，

所以 $x_1 + 1, x_2 + 1, x + 1$ 同号. 则 $\dfrac{1}{x_1 + 1} + \dfrac{1}{x_2 + 1} = \dfrac{2}{x + 1}$

因此 $x = 2\dfrac{x_1x_2 + x_1 + x_2 + 1}{x_1 + x_2 + 2} - 1 = \dfrac{2 - k}{k + 2}$ ①，

$$y = k(x + 1) - 1 = k \cdot \left(\frac{2 - k}{k + 2} + 1\right) - 1 = \frac{3k - 2}{k + 2}$$ ②，

由①得 $k = \dfrac{2 - 2x}{x + 1}$，代入②得 $y = \dfrac{3 \cdot \dfrac{2 - 2x}{x + 1} - 2}{\dfrac{2 - 2x}{x + 1} + 2} = 1 - 2x$，即 $2x - y + 1 = 0$， （15 分）

又因为 $k > -2 + 2\sqrt{2}$ 或 $k < -2 - 2\sqrt{2}$，所以 $x = \dfrac{4}{k + 2} - 1$ 的取值范围是

$-\sqrt{2} - 1 < x < \sqrt{2} - 1$ 且 $x \ne -1$，

因此点 $Q$ 的轨迹方程是 $2x - y + 1 = 0$（$-\sqrt{2} - 1 < x < \sqrt{2} - 1$ 且 $x \ne -1$）. （20 分）

**16.** 已知 $m$ 为实数，数列 $\{a_n\}$ 的前 $n$ 项和为 $S_n$，满足：$S_n = \dfrac{9}{8}a_n - \dfrac{4}{3} \times 3^n + m$，且 $a_n \ge \dfrac{64}{3}$ 对任何的正整数 $n$ 恒成立.

求证：当 $m$ 取到最大值时，对任何正整数 $n$ 都有 $\sum\limits_{k=1}^{n} \dfrac{3^k}{S_k} < \dfrac{3}{16}$.

**证明** 当 $n = 1$ 时，由 $a_1 = \dfrac{9}{8}a_1 - 4 + m$ 得 $a_1 = 8(4 - m)$，

当 $n \ge 1$ 时，$S_n = \dfrac{9}{8}a_n - \dfrac{4}{3} \times 3^n + m$，$S_{n+1} = \dfrac{9}{8}a_{n+1} - \dfrac{4}{3} \times 3^{n+1} + m$，

$$\therefore a_{n+1} = \frac{9}{8}a_{n+1} - \frac{9}{8}a_n - \frac{8}{3} \times 3^n，\text{即}\ a_{n+1} = 9a_n + \frac{64}{3} \times 3^n$$ （5 分）

$$\therefore a_{n+1} + \frac{32}{9} \times 3^{n+1} = 9\left(a_n + \frac{32}{9} \times 3^n\right)$$

$$\therefore a_n + \frac{32}{9} \times 3^n = \left(a_1 + \frac{32}{3}\right) \times 9^{n-1}$$

即 $a_n = \dfrac{8}{27}(16 - 3m) \times 9^n - \dfrac{32}{9} \times 3^n$ （10 分）

由条件知，$\dfrac{8}{27}(16 - 3m) \times 9^n - \dfrac{32}{9} \times 3^n \ge \dfrac{64}{3}$ 对任何正整数 $n$ 恒成立，

即 $\dfrac{8}{27}(16 - 3m) \ge \dfrac{64}{3} \times \dfrac{1}{9^n} + \dfrac{32}{9} \times \dfrac{1}{3^n}$ 对任何正整数 $n$ 恒成立，

由于 $\dfrac{64}{3} \times \dfrac{1}{9^n} + \dfrac{32}{9} \times \dfrac{1}{3^n}$ 在 $n = 1$ 时取最大值 $\dfrac{64}{3} \times \dfrac{1}{9} + \dfrac{32}{9} \times \dfrac{1}{3} = \dfrac{96}{27}$，

于是 $\dfrac{8}{27}(16 - 3m) \ge \dfrac{96}{27}$，解得 $m \le \dfrac{4}{3}$.

由上式知道 $m$ 的最大值为 $\dfrac{4}{3}$. （15 分）

当 $m = \dfrac{4}{3}$ 时，$a_n = \dfrac{32}{9} \times 9^n - \dfrac{32}{9} \times 3^n$，

于是 $S_n = \dfrac{9}{8}\left(\dfrac{32}{9} \times 9^n - \dfrac{32}{9} \times 3^n\right) - \dfrac{4}{3} \times 3^n + \dfrac{4}{3}$

$$= \frac{4}{3}\left[3 \times (3^n)^2 - 4 \times 3^n + 1\right] = \frac{4}{3}(3^{n+1} - 1)(3^n - 1)$$

所以 $\sum\limits_{k=1}^{n} \dfrac{3^k}{S_k} = \dfrac{3}{4}\sum\limits_{k=1}^{n} \dfrac{3^k}{(3^{k+1} - 1)(3^k - 1)} = \dfrac{3}{8}\sum\limits_{k=1}^{n} \left(\dfrac{1}{3^k - 1} - \dfrac{1}{3^{k+1} - 1}\right)$

$$= \frac{3}{8}\left(\frac{1}{3 - 1} - \frac{1}{3^{n+1} - 1}\right) < \frac{3}{8} \times \frac{1}{2} = \frac{3}{16}.$$ （20 分）
