# 全国高中数学联赛模拟试题（23）

## 第一试

### 一、填空题（本题满分 64 分，每小题 8 分）

**1.** 已知 $y = f(x) + x^3$ 为偶函数，且 $f(10) = 10$. 若函数 $g(x) = f(x) + 5$，则 $g(-10)$ 的值为 ________.

**2.** 已知在 $\triangle ABC$ 中，$AB = 2$，$AC = 1$，$\angle BAC = 120^\circ$，$O$ 是 $\triangle ABC$ 的外心，且 $\vec{AO} = \lambda\vec{AB} + \mu\vec{AC}$，则 $\lambda + \mu = $ ________.

**3.** 空间中 $n\ (n \geqslant 3)$ 个平面，其中任意三个平面无公共垂线. 现有如下四个结论：

(1) 没有任何两个平面互相平行；

(2) 没有任何三个平面相交于一条直线；

(3) 平面间的任意两条交线都不平行；

(4) 平面间的每一条交线均与 $n - 2$ 个平面相交.

其中，正确的个数为 ________.

**4.** 对于平面直角坐标系中的任意两点 $P_1(x_1, y_1)$、$P_2(x_2, y_2)$，我们称 $d(P_1, P_2) = |x_1 - x_2| + |y_1 - y_2|$ 为 $P_1$ 与 $P_2$ 的直角距离. 若 $P_0(x_0, y_0)$ 是一定点，$Q(x, y)$ 是曲线 $F(x, y) = 0$ 的动点，我们称 $d(P_0, Q)$ 的最小值为点 $P_0$ 到曲线 $F(x, y) = 0$ 的直角距离. 则 $M(-1, 0)$ 到抛物线 $x^2 = y$ 的直角距离是 ________.

**5.** 若数列 $\{a_n\}$ 满足 $a_1 = \dfrac{2}{3}$，$a_{n+1} - a_n = \sqrt{\dfrac{2}{3}(a_{n+1} + a_n)}$，则 $a_{2015} = $ ________.

**6.** 设 $x \in \mathbf{R}$，则函数 $y = \sqrt{\dfrac{1}{1 + x^2}} + 2\sqrt{\dfrac{1}{1 + x}}$ 的最大值为 ________.

**7.** 对任意的 $x \in \left[-\dfrac{6\pi}{5}, \dfrac{\pi}{2}\right]$，不等式 $\sin^3 x + a\sin x + a + 3 \geqslant 0$ 恒成立. 则实数 $a$ 的取值范围是 ________.

**8.** 在平面直角坐标系中，将点集 $\{(m, n) \mid m, n \in \mathbf{N}, 1 \leqslant m, n \leqslant 6\}$ 中的点染成红色或蓝色. 那么，每个单位正方形恰有两个红色顶点的不同染色方案的个数是 ________.

### 二、解答题（本题满分 56 分）

**9.** （16 分）试求实数 $k$ 的最大可能值，使得不等式 $\dfrac{2(a^2 + kab + b^2)}{(k+2)(a+b)} \geqslant \sqrt{ab}$ 对任意正实数 $a, b$ 都成立.

**10.** （20 分）甲、乙两人轮流掷一颗骰子，第一次甲掷，第二次乙掷，…… 某次掷完后，如果最后三次掷出的点数之和是 2 的倍数，且最后两次掷出的点数之和不是 3 的倍数，则游戏结束，甲获胜. 如果最后两次掷出的点数之和是 3 的倍数，且最后三次掷出的点数之和不是 2 的倍数，游戏也结束，乙获胜. 其余情况下，游戏继续进行. 试求乙获胜的概率.

注　如果掷次数不足三次，则"最后三次"掷出点数和不是 2 的倍数.

**11.** （20 分）已知椭圆 $C$：$\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1$，且作不与 $x$ 轴垂直的直线 $l$ 与椭圆 $C$ 相交于 $P$ 和 $Q$ 两点，点 $S$ 与点 $P$ 关于 $x$ 轴对称. 求 $\triangle OSQ$ 面积的最大值.

### 二（本题满分 40 分）

设 $p$ 为大于 1 的整数，集合 $F_p$ 表示各项均为非负整数，且满足递推关系

$$a_{n+1} = (p+1)a_n - pa_{n-1} \quad (n \geqslant 1)$$

的所有非负数数列 $\{a_n\}$ 的集合.

求证：存在 $F_p$ 中的一个数列 $\{a_n\}$，满足对于任意的 $\{b_n\} \in F_p$，$a_n \leqslant b_n$ 对所有的非负整数 $n$ 都成立.

### 三（本题满分 50 分）

设 $n$ 为正整数，$[x]$ 为不超过实数 $x$ 的最大整数，$\{x\} = x - [x]$.

(1) 求所有满足 $\displaystyle\sum_{k=1}^{2013} \left[\frac{kn}{2013}\right] = 2013 + n$ 的正整数 $n$；

(2) 求所有使得 $\displaystyle\sum_{k=1}^{2013} \left\{\frac{kn}{2013}\right\}$ 取得最大值的正整数 $n$，并求出这个最大值.

### 四（本题满分 50 分）

沿着圆桌的边缘等间距地放着 $n$ 个碗. 某人做游戏，他先任选一个碗，放入一粒豌豆，再在顺时针方向的相邻碗中放入一粒豌豆. 然后一直沿着顺时针方向运动，跳过一个碗，在下一个碗里放入一粒豌豆，再跳过两个碗，在下一个碗里放入一粒豌豆. 如此一直进行下去，直到每个碗里都有豌豆为止. 试问：对怎样的正整数 $n$，他可在有限步内结束游戏？
