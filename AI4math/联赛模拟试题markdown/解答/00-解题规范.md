# 解题规范 (所有子任务共用)

本文件规定每一份试卷解答的 Markdown 输出格式与书写规范. 解题时严格遵守.

## 一, 文件与路径

- 输入: `../01-第一部分-模拟试题/模拟试题XX.md` 或 `../02-第二部分-邀请赛/xxx.md`
- 输出: 本目录 (`解答/`) 下与输入文件同名的 `.md` 文件 (去掉 `(完成)` 后缀).
- 只写输出文件, 不要改动试卷原文件, 不要改动本规范文件.

## 二, 内容要求

1. 第一试 8 道填空题: 必须给出完整推导过程与最终答案, 不允许只写答案.
2. 第一试 3 道解答题: 详细书写, 关键步骤不能跳.
3. 第二试 4 道大题: 详细书写, 每题另加 `问题背景` 与 `可能推广` 两个小节.
4. 平面几何题若无图, 用文字描述图形或改用坐标/三角/复数等可自洽的解法, 并在解答开头说明图形假设.
5. 结论与数值答案要自我检验 (代回原式, 特殊值, 量级, 边界情形). 可用 bash + python 做数值验证.
6. 若原试卷因扫描缺页不完整, 在文件开头用一段 `> 说明:` 注明缺失的题号, 并只解现存题目.

```

**答案:** ...

**解答:** ...

**解答:** ...
**总结:** ...

...

**问题陈述:** ...

**解答:** ...

- 本卷考点分布
- 难度排序与易错点
- 可迁移的通用方法
```

## 四, 书写规范

- 全文中文. 不使用中文标点: 逗号用 `,` (顿号也用 `,`), 句号用 `.`, 分号用 `;`, 冒号用 `:`. 引号用 `"` 或 `` ` ``. 括号用半角 `(...)`.
- 中英文, 标点与公式之间留空格.
- 行内公式用 `$...$`, 独立公式用 `$$...$$` (前后各留空行).
- `\sum, \prod, \lim, \max, \min, \sup, \inf, \limsup, \liminf` 后一律加 `\limits`, 例如 `$\sum\limits_{i=1}^{n} a_i$`, `$\lim\limits_{n\to\infty} a_n$`.
- 术语与人名保留英文 (AM-GM, Menelaus, Ceva, Cauchy, Schur, Lucas 等).
- 答案与推理不要用 `\textbf` 之类 LaTeX 文本命令代替 Markdown 强调; Markdown 中用 `**...**`, 用 `###` 分级.
- 需要列表时用 `-` 或有序列表.

## 五, 详细程度

- 每份解答总量建议 200 行以上 Markdown, 填空题每题不少于 15 行, 大题每题不少于 40 行.
- 推导给出理由 (为何能这样放缩, 为何构造满足条件), 而不只是式子堆叠.
