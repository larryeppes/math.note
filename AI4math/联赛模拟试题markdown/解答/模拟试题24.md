# 全国高中数学联赛模拟试题 (24) 详细解答

> 说明: 本卷有三处题面需要说明.
> 1. 第一试第 1 题的条件 "$a > 0$ 且 $a \ne -1$" 应为 "$a > 0$ 且 $a \ne 1$", 否则条件恒成立而与对数底数的要求不符. 解答按 $a>0$, $a\ne 1$ 处理.
> 2. 第一试第 3 题说 $E$ 是 "$BC$ 延长线上任意一点", 但直接计算表明向量 $\overrightarrow{BF}$ 与 $\overrightarrow{EB}$ 的夹角随 $E$ 变化, 不是常数 (见该题). 故此题按"求夹角与 $E$ 的位置关系"完整解答, 并指出常见的特殊取值.
> 3. 第一试第 7 题条件关于 $B, D$ 对称且 $AB = AD$, 故按 $CB = CD$ 的对称构型求解, 最后用显式坐标验证全部条件成立.

## 第一试

### 一, 填空题 (每小题 8 分)

#### 第 1 题

**答案:** $(a,b) = \left(\dfrac{\sqrt2}{2}, 1\right)$.

**问题陈述:** $f(x) = \log_a\left(x + \sqrt{bx^2 + 2a^2}\right)$, $a>0$, $a\ne 1$, 且 $f$ 为奇函数, 求 $(a,b)$.

**解答:** 奇函数要求定义域关于原点对称, 且 $f(x) + f(-x) = 0$ 对定义域内一切 $x$ 成立.

先看定义域. 由于根式有意义需 $bx^2 + 2a^2 \ge 0$ 对一切 $x$ 成立, 且真数 $x + \sqrt{bx^2+2a^2} > 0$. 若 $b < 1$, 则当 $x \to -\infty$ 时 $\sqrt{bx^2 + 2a^2} < |x|$, 真数趋于 $-\infty$, 定义域不是 $\mathbf R$; 而奇函数的定义域必须对称, 若定义域不是 $\mathbf R$ 就必须恰好是有界对称区间, 但 $x + \sqrt{bx^2+2a^2}$ 在 $x \to +\infty$ 时恒正, 在 $x \to -\infty$ 时恒负, 故不可能对称. 于是 $b \ge 1$, 定义域为 $\mathbf R$.

在 $\mathbf R$ 上计算

$$f(x) + f(-x) = \log_a\left[\left(x + \sqrt{bx^2+2a^2}\right)\left(-x + \sqrt{bx^2+2a^2}\right)\right] = \log_a\left[(b-1)x^2 + 2a^2\right].$$

这是关于 $x$ 的多项式取对数, 要求它对一切实数 $x$ 恒等于 $0$, 只能有

$$(b-1)x^2 + 2a^2 \equiv 1,$$

即 $b - 1 = 0$ 且 $2a^2 = 1$. 结合 $a>0$ 得 $a = \dfrac{\sqrt2}{2}$.

**检验:** $f(x) = \log_a\left(x + \sqrt{x^2+1}\right)$, 而 $\sqrt{x^2+1} - x = \dfrac{1}{\sqrt{x^2+1}+x}$, 故 $f(-x) = \log_a\dfrac{1}{\sqrt{x^2+1}+x} = -f(x)$, 且定义域为 $\mathbf R$. 条件满足.

**点评:** 关键是先确定 $b \ge 1$ 使定义域为 $\mathbf R$, 再用 $f(x)+f(-x)\equiv 0$ 比较系数. 不要漏掉定义域对称性的检验.

#### 第 2 题

**答案:** $\angle C = 30^\circ$, 即 $\dfrac{\pi}{6}$.

**问题陈述:** $\triangle ABC$ 中 $3\sin A + 4\cos B = 6$, $4\sin B + 3\cos A = 1$, 求 $\angle C$.

**解答:** 把两式平方相加, 交叉项正好合成正弦的和角公式:

$$9\sin^2 A + 24\sin A\cos B + 16\cos^2 B + 16\sin^2 B + 24\sin B\cos A + 9\cos^2 A = 36 + 1.$$

整理得

$$9\left(\sin^2A + \cos^2A\right) + 16\left(\cos^2B + \sin^2B\right) + 24\left(\sin A\cos B + \cos A\sin B\right) = 37,$$

即 $25 + 24\sin(A+B) = 37$, 故

$$\sin(A+B) = \frac12.$$

因 $0 < A + B < 180^\circ$, 得 $A + B = 30^\circ$ 或 $A + B = 150^\circ$, 即 $C = 150^\circ$ 或 $C = 30^\circ$.

排除 $C = 150^\circ$. 此时 $A + B = 30^\circ$, 于是 $A < 30^\circ$, $\sin A < \dfrac12$, 又有 $\cos B \le 1$, 故

$$3\sin A + 4\cos B < \frac32 + 4 = \frac{11}{2} < 6,$$

与第一式矛盾. 故 $A + B = 150^\circ$, 即 $C = 30^\circ$.

**存在性检验:** 令 $B = 150^\circ - A$, 由 $\cos(150^\circ - A) = -\dfrac{\sqrt3}{2}\cos A + \dfrac12\sin A$, $\sin(150^\circ - A) = \dfrac12\cos A + \dfrac{\sqrt3}{2}\sin A$, 两条件化为

$$5\sin A - 2\sqrt3\cos A = 6, \qquad 2\sqrt3\sin A + 5\cos A = 1.$$

系数行列式为 $25 + 12 = 37$, 解得 $\sin A = \dfrac{30+2\sqrt3}{37} > 0$, $\cos A = \dfrac{5 - 12\sqrt3}{37}$, 且 $\sin^2A + \cos^2A = \dfrac{1369}{37^2} = 1$, 确实给出合法的角 $A \approx 115.2^\circ$, $B \approx 34.8^\circ$. 所以 $C = 30^\circ$ 可实现.

**点评:** "平方相加" 是本类题的标准动作, 它把两个方程化为一个只含 $A+B$ 的方程; 但 $\sin(A+B) = \frac12$ 有两解, 必须用放缩排除一解.

#### 第 3 题

**答案:** 夹角不是常数, 它随 $E$ 变化. 设菱形边长为 1, $BE = t$ ($t>1$, $E$ 在 $BC$ 延长线上越过 $C$), 则

$$\cos\angle\left(\overrightarrow{BF}, \overrightarrow{EB}\right) = -\frac{t+1}{2\sqrt{t^2 - t + 1}},$$

夹角取值范围为 $(120^\circ, 180^\circ)$; 特别地当 $CE = CB$ (即 $t = 2$) 时夹角为 $150^\circ$, 当 $t \to +\infty$ 时夹角趋于 $120^\circ$.

**问题陈述:** 菱形 $ABCD$ 边长 1, $\angle ABC = 120^\circ$, $E$ 在 $BC$ 延长线上, $AE$ 交 $CD$ 于 $F$, 求 $\overrightarrow{BF}$ 与 $\overrightarrow{EB}$ 的夹角.

**解答:** 取坐标. 令 $B = (0,0)$, $C = (1,0)$, 由 $\angle ABC = 120^\circ$ 得

$$A = \left(\cos 120^\circ, \sin 120^\circ\right) = \left(-\frac12, \frac{\sqrt3}{2}\right), \qquad D = A + C - B = \left(\frac12, \frac{\sqrt3}{2}\right).$$

容易验证 $\left|AB\right| = \left|BC\right| = \left|CD\right| = \left|DA\right| = 1$, 且 $AB \parallel CD$, 故这是所求菱形.

设 $E = (t, 0)$, $t > 1$ ($E$ 越过 $C$ 之后). 直线 $CD$ 上的点可写成

$$F = C + s(D - C) = \left(1 - \frac{s}{2},\ \frac{\sqrt3}{2}s\right), \quad 0 \le s \le 1.$$

直线 $AE$ 上的点可写成 $A + u(E - A)$ 的形式. 由纵坐标相等:

$$\frac{\sqrt3}{2}(1 - u) = \frac{\sqrt3}{2}s \Longrightarrow s = 1 - u.$$

由横坐标相等:

$$-\frac12 + u\left(t + \frac12\right) = 1 - \frac{s}{2} = \frac12 + \frac{u}{2} \Longrightarrow u\,t = 1 \Longrightarrow u = \frac1t.$$

于是 $s = 1 - \dfrac1t$, 且

$$F = \left(1 - \frac{1}{2}\left(1 - \frac1t\right),\ \frac{\sqrt3}{2}\left(1 - \frac1t\right)\right) = \left(\frac12 + \frac{1}{2t},\ \frac{\sqrt3}{2}\cdot\frac{t-1}{t}\right).$$

于是

$$\overrightarrow{BF} = \left(\frac{t+1}{2t},\ \frac{\sqrt3(t-1)}{2t}\right), \qquad \overrightarrow{EB} = (-t, 0).$$

计算模长与内积:

$$\left|\overrightarrow{BF}\right|^2 = \frac{(t+1)^2 + 3(t-1)^2}{4t^2} = \frac{4t^2 - 4t + 4}{4t^2} = \frac{t^2 - t + 1}{t^2},$$

$$\overrightarrow{BF}\cdot\overrightarrow{EB} = -\frac{t+1}{2t}\cdot t = -\frac{t+1}{2}, \qquad \left|\overrightarrow{EB}\right| = t.$$

故夹角的余弦为

$$\cos\theta = \frac{-\dfrac{t+1}{2}}{t\cdot\dfrac{\sqrt{t^2-t+1}}{t}} = -\frac{t+1}{2\sqrt{t^2 - t + 1}}.$$

这个值确实随 $t$ 变化: $t = 2$ 时 $\cos\theta = -\dfrac{3}{2\sqrt3} = -\dfrac{\sqrt3}{2}$, $\theta = 150^\circ$; $t = 4$ 时 $\cos\theta = -\dfrac{5}{2\sqrt{13}} \approx -0.693$, $\theta \approx 133.9^\circ$. 又 $\cos\theta \to -1$ ($t \to 1^+$), $\cos\theta \to -\dfrac12$ ($t \to +\infty$), 故夹角的取值范围是 $(120^\circ, 180^\circ)$.

若把 $E$ 改为在 $BC$ 的反向延长线上, 即 $E = (-t,0)$, $t>0$, 则 $AE$ 与直线 $CD$ 的交点落在 $CD$ 的延长线上 ($s = 1 + \dfrac1t > 1$, 即越过 $D$), 不再满足"交线段 $CD$ 于 $F$". 此时 $F = \left(\dfrac{t-1}{2t},\ \dfrac{\sqrt3(t+1)}{2t}\right)$, $\overrightarrow{BF}$ 与 $\overrightarrow{EB} = (t,0)$ 的夹角满 $\tan\theta = \sqrt3\cdot\dfrac{t+1}{t-1}$, 同样随 $t$ 变化, 取值在 $(60^\circ, 90^\circ)$ 内. 可见两种延长方向都没有恒定夹角.

**点评:** 题面"任意一点"与答案应为常数矛盾. 用坐标法可以直接看出: $F$ 在 $CD$ 上滑动时 $\overrightarrow{BF}$ 的方向随之改变, 而 $\overrightarrow{EB}$ 始终沿 $BC$ 方向, 夹角必然变动. 常见参考答案的 $150^\circ$ 对应 $CE = CB$ 的特殊位置; 极限位置 $120^\circ$ 则对应 $E$ 跑到无穷远 ($BF \parallel BC$ 的极端情形).

#### 第 4 题

**答案:** $8$.

**问题陈述:** 复系数方程 $(4+3\mathrm i)x^2 + mx + 4 - 3\mathrm i = 0$ 有实根, 求 $|m|$ 的最小值.

**解答:** 设实根为 $r \in \mathbf R$. 若 $r = 0$, 代入得 $4 - 3\mathrm i = 0$, 矛盾, 故 $r \ne 0$. 由方程解出

$$m = -\frac{(4+3\mathrm i)r^2 + (4 - 3\mathrm i)}{r} = -\left[(4+3\mathrm i)r + \frac{4-3\mathrm i}{r}\right].$$

记 $4 + 3\mathrm i = 5\mathrm e^{\mathrm i\alpha}$, 其中 $\cos\alpha = \dfrac45$, $\sin\alpha = \dfrac35$. 则 $4 - 3\mathrm i = 5\mathrm e^{-\mathrm i\alpha}$, 于是

$$m = -5\left(r\mathrm e^{\mathrm i\alpha} + \frac{1}{r}\mathrm e^{-\mathrm i\alpha}\right), \qquad |m| = 5\left|\left(r + \frac1r\right)\cos\alpha + \mathrm i\left(r - \frac1r\right)\sin\alpha\right|.$$

两边平方:

$$|m|^2 = 25\left[\left(r+\frac1r\right)^2\frac{16}{25} + \left(r - \frac1r\right)^2\frac{9}{25}\right] = 16\left(r+\frac1r\right)^2 + 9\left(r - \frac1r\right)^2.$$

展开并按 $r^2 + r^{-2}$ 整理:

$$|m|^2 = 16\left(r^2 + 2 + r^{-2}\right) + 9\left(r^2 - 2 + r^{-2}\right) = 25\left(r^2 + r^{-2}\right) + 14.$$

由 $r^2 + r^{-2} \ge 2$ (等号当 $r^2 = 1$) 得 $|m|^2 \ge 50 + 14 = 64$, 即 $|m| \ge 8$.

取 $r = 1$ 得 $m = -\left[(4+3\mathrm i) + (4-3\mathrm i)\right] = -8$; 取 $r = -1$ 得 $m = 8$. 两者都使原方程有实根 $\pm 1$.

**检验:** $m = 8$ 时方程为 $(4+3\mathrm i)x^2 + 8x + 4 - 3\mathrm i = 0$, 代入 $x = -1$: $(4+3\mathrm i) - 8 + 4 - 3\mathrm i = 0$ 成立.

**点评:** 也可用"实系数部分与虚系数部分同时为零"的写法: 把 $x = r$ 代入并分离实虚部得两个实方程, 消去 $r$ 得到 $m$ 的轨迹, 结论相同. 关键是注意 $r$ 可正可负, 并且 $|m|^2$ 只依赖 $r^2 + r^{-2}$.

#### 第 5 题

**答案:** $-\dfrac12 < a < \dfrac12$, 即 $a \in \left(-\dfrac12, \dfrac12\right)$.

**问题陈述:** $f(x) = \lg\left(\sin^6x + \cos^6x + a\sin x\cos x\right)$ 的定义域为 $\mathbf R$, 求 $a$ 的范围.

**解答:** 定义域为 $\mathbf R$ 等价于

$$g(x) = \sin^6x + \cos^6x + a\sin x\cos x > 0 \quad \text{对一切 } x \in \mathbf R.$$

用 $\sin^6x + \cos^6x = 1 - 3\sin^2x\cos^2x = 1 - \dfrac34\sin^22x$, 并令 $u = \sin 2x \in [-1,1]$, 则 $\sin x\cos x = \dfrac{u}{2}$, 于是

$$g = 1 - \frac34u^2 + \frac{a}{2}u =: h(u), \qquad u \in [-1,1].$$

$h$ 是开口向下的二次函数, 它在闭区间 $[-1,1]$ 上的最小值必在端点取到, 所以 $h(u) > 0$ 对一切 $u \in [-1,1]$ 成立当且仅当

$$h(1) = 1 - \frac34 + \frac a2 = \frac14 + \frac a2 > 0, \qquad h(-1) = 1 - \frac34 - \frac a2 = \frac14 - \frac a2 > 0.$$

两式给出 $a > -\dfrac12$ 与 $a < \dfrac12$, 即 $-\dfrac12 < a < \dfrac12$.

**检验:** 当 $u = \pm 1$ 时 $x = \dfrac{\pi}{4}$ 与 $x = -\dfrac{\pi}{4}$, 此时 $\sin^6x + \cos^6x = \dfrac28 = \dfrac14$, $\sin x\cos x = \pm\dfrac12$, 真数为 $\dfrac14 \pm \dfrac a2$, 恰好是最危险的两个值. 端点严格不等号不可放宽 (取等时真数为 $0$, 无定义).

**点评:** 用二倍角把问题化为一个二次函数在 $[-1,1]$ 上的正性, 再用"开口向下, 最小值在端点"这一简单事实, 避免了对顶点位置的讨论.

#### 第 6 题

**答案:** $\dfrac{n(n^2+1)}{2}$.

**问题陈述:** 把 $1,2,\dots,n^2$ 排成 $n$ 行 $n$ 列, 第 $i$ 行第 $j$ 列为 $(i-1)n + j$. 每次取一个数并划去它所在的行与列, 共取 $n$ 次, 求所取 $n$ 个数之和.

**解答:** 设在第 $k$ 次取了位于第 $i_k$ 行第 $j_k$ 列的数 $a_k$, 则

$$a_k = (i_k - 1)n + j_k.$$

由于每次划去所取数所在的行与列, 被取过的行不会再被取, 被取过的列也不会再被取, 故 $i_1,i_2,\dots,i_n$ 两两不同, 从而恰是 $1,2,\dots,n$ 的一个排列; 同理 $j_1,j_2,\dots,j_n$ 也是 $1,2,\dots,n$ 的一个排列.

于是

$$\sum\limits_{k=1}^{n} a_k = \sum\limits_{k=1}^{n}\left[(i_k - 1)n + j_k\right] = n\sum\limits_{k=1}^{n} i_k - n^2 + \sum\limits_{k=1}^{n} j_k.$$

代入两个排列的和 $\sum\limits_{k=1}^n i_k = \sum\limits_{k=1}^n j_k = \dfrac{n(n+1)}{2}$:

$$\sum\limits_{k=1}^{n} a_k = n\cdot\frac{n(n+1)}{2} - n^2 + \frac{n(n+1)}{2} = \frac{n^2(n+1) + n(n+1) - 2n^2}{2} = \frac{n^3 + n}{2} = \frac{n(n^2+1)}{2}.$$

(最后一个等号用到 $n^2(n+1) + n(n+1) - 2n^2 = n^3 + n^2 + n^2 + n - 2n^2 = n^3+n$.)

**检验:** $n = 2$ 时表为 $\begin{pmatrix} 1 & 2 \\ 3 & 4\end{pmatrix}$, 无论怎样取 (取 $1$ 后必取 $4$, 或取 $2$ 后必取 $3$) 和都是 $5 = \dfrac{2\cdot 5}{2}$; 公式给出 $5$, 符合.

**点评:** 本题与"取法"无关, 本质原因是取出的 $n$ 个数必然对应"行号构成一个排列, 列号构成一个排列", 于是和式只依赖两个排列的和. 这是"不变量"思想的典型例子: 先证明所求和与操作顺序无关, 再算最方便的那一组.

#### 第 7 题

**答案:** $\dfrac{1}{24}$.

**问题陈述:** 四面体 $ABCD$ 表面积为 1, $AB = AD$, $BD = \dfrac{\sqrt2}{2}$, 且

$$\angle ABD + \angle DBC + \angle CBA = \angle ADB + \angle BDC + \angle CDA = 180^\circ, \qquad \angle ACB + \angle ACD + \angle BCD = 90^\circ,$$

求体积.

**解答:** 数据与两个 $180^\circ$ 条件在交换 $B,D$ 下对称, 且 $AB = AD$, 故按对称构型求解: 设 $CB = CD = u$, $AB = AD = x$, 记

$$\gamma = \angle ABD = \angle ADB, \quad \psi = \angle DBC = \angle BDC, \quad \alpha = \angle ABC.$$

由三角形 $ABD$ 与 $BCD$ 都是等腰三角形, $\angle BAD = 180^\circ - 2\gamma$, $\angle BCD = 180^\circ - 2\psi$, 且

$$\cos\gamma = \frac{BD/2}{x} = \frac{\sqrt2}{4x}, \qquad \cos\psi = \frac{\sqrt2}{4u}. \tag{1}$$

由对称性, $\triangle ABC \cong \triangle ADC$, 故 $\angle ADC = \angle ABC = \alpha$, $\angle ACB = \angle ACD =: \theta$. 三个条件分别化为

$$\gamma + \psi + \alpha = 180^\circ, \qquad 2\theta + \left(180^\circ - 2\psi\right) = 90^\circ. \tag{2}$$

第二式给出 $\theta = \psi - 45^\circ$, 于是

$$\angle BAC = 180^\circ - \alpha - \theta = 180^\circ - \left(180^\circ - \gamma - \psi\right) - \left(\psi - 45^\circ\right) = \gamma + 45^\circ.$$

在 $\triangle ABC$ 中用正弦定理 ($AB = x$, $BC = u$):

$$\frac{x}{\sin\theta} = \frac{u}{\sin\left(\gamma + 45^\circ\right)} \Longrightarrow \frac{\cos\psi}{\cos\gamma} = \frac{x}{u} = \frac{\sin\left(\psi - 45^\circ\right)}{\sin\left(\gamma+45^\circ\right)}.$$

由 (1) 有 $x/u = \cos\psi/\cos\gamma$. 展开

$$\cos\psi\cdot\frac{\sqrt2}{2}\left(\sin\gamma + \cos\gamma\right) = \cos\gamma\cdot\frac{\sqrt2}{2}\left(\sin\psi - \cos\psi\right),$$

即 $\cos\psi\sin\gamma + \cos\psi\cos\gamma = \cos\gamma\sin\psi - \cos\gamma\cos\psi$, 除以 $\cos\gamma\cos\psi$ 得

$$\tan\psi = \tan\gamma + 2. \tag{3}$$

下面用面积条件定 $\gamma$. 记 $t = \tan\gamma$, $T = \tan\psi = t + 2$, 则 $\cos\gamma = \dfrac{1}{\sqrt{1+t^2}}$, 由 (1) 得

$$x^2 = \frac{1+t^2}{8}, \qquad u^2 = \frac{1+T^2}{8}, \qquad \sin 2\gamma = \frac{2t}{1+t^2}, \qquad \sin 2\psi = \frac{2T}{1+T^2}.$$

四面积依次为

$$[ABD] = \frac12x^2\sin 2\gamma = \frac{t}{8}, \qquad [BCD] = \frac12u^2\sin 2\psi = \frac{T}{8},$$

$$[ABC] = [ACD] = \frac12xu\sin\alpha, \qquad \sin\alpha = \sin\left(\gamma+\psi\right) = \frac{t + T}{\sqrt{(1+t^2)(1+T^2)}}.$$

故 $[ABC] = [ACD] = \dfrac{t+T}{16}$, 总表面积

$$S = \frac{t}{8} + \frac{T}{8} + \frac{t+T}{8} = \frac{t + T}{4} = \frac{2t+2}{4} = \frac{t+1}{2}.$$

由 $S = 1$ 得 $t = 1$, 即 $\gamma = 45^\circ$, $\tan\psi = 3$, 于是

$$x = \frac12, \qquad u = \frac{\sqrt5}{2}, \qquad \sin\psi = \frac{3}{\sqrt{10}}, \quad \cos\psi = \frac{1}{\sqrt{10}}.$$

由正弦定理 $AC = \dfrac{x\sin\alpha}{\sin\theta}$, 其中 $\sin\alpha = \sin\left(45^\circ+\psi\right) = \dfrac{2}{\sqrt5}$, $\sin\theta = \sin\left(\psi - 45^\circ\right) = \dfrac{1}{\sqrt5}$, 得 $AC = 1$.

**计算体积.** 取 $M$ 为 $BD$ 中点, 令

$$B = \left(-\frac{\sqrt2}{4},0,0\right), \quad D = \left(\frac{\sqrt2}{4},0,0\right), \quad A = \left(0,\frac{\sqrt2}{4},0\right), \quad C = \left(0,\frac{\sqrt2}{4},1\right).$$

逐项验证: $\left|BD\right| = \dfrac{\sqrt2}{2}$; $\left|AB\right| = \left|AD\right| = \sqrt{\dfrac{2}{16}+\dfrac{2}{16}} = \dfrac12$; $\left|CB\right| = \left|CD\right| = \sqrt{\dfrac{2}{16}+\dfrac{2}{16}+1} = \dfrac{\sqrt5}{2}$; $\left|AC\right| = 1$. 再验证角条件:

$$\cos\angle ABD = \frac{BD/2}{AB} = \frac{\sqrt2}{2} \Rightarrow \angle ABD = 45^\circ, \qquad \cos\angle DBC = \frac{BD/2}{BC} = \frac{1}{\sqrt{10}} \Rightarrow \angle DBC \approx 71.57^\circ,$$

$$\cos\angle CBA = \frac{AB^2 + BC^2 - AC^2}{2\cdot AB\cdot BC} = \frac{\frac14 + \frac54 - 1}{\frac{\sqrt5}{2}} = \frac{1}{\sqrt5} \Rightarrow \angle CBA \approx 63.43^\circ.$$

三者之和 $45^\circ + 71.57^\circ + 63.43^\circ = 180^\circ$; 由对称性 $D$ 处的三个面角和也为 $180^\circ$; 又

$$\cos\angle ACB = \frac{AC^2+BC^2 - AB^2}{2\cdot AC\cdot BC} = \frac{1 + \frac54 - \frac14}{\sqrt5} = \frac{2}{\sqrt5} \Rightarrow \angle ACB \approx 26.57^\circ,$$

$$\cos\angle BCD = \frac{2BC^2 - BD^2}{2BC^2} = 1 - \frac{1/2}{5/2} = \frac45 \Rightarrow \angle BCD \approx 36.87^\circ,$$

故 $\angle ACB + \angle ACD + \angle BCD = 26.57^\circ + 26.57^\circ + 36.87^\circ = 90.01^\circ$ (精确值为 $90^\circ$, 因为 $\arccos\frac{2}{\sqrt5}$ 的两倍加 $\arccos\frac45$ 恰为直角). 面积 $\dfrac18 + \dfrac38 + 2\cdot\dfrac14 = 1$ 也符合.

体积: $\overrightarrow{AB} = \left(-\frac{\sqrt2}{4},-\frac{\sqrt2}{4},0\right)$, $\overrightarrow{AD} = \left(\frac{\sqrt2}{4},-\frac{\sqrt2}{4},0\right)$, $\overrightarrow{AC} = (0,0,1)$, 而

$$\overrightarrow{AB}\times\overrightarrow{AD} = \left(0,0,\frac{2}{16}+\frac{2}{16}\right) = \left(0,0,\frac14\right),$$

故

$$V = \frac16\left|\left(\overrightarrow{AB}\times\overrightarrow{AD}\right)\cdot\overrightarrow{AC}\right| = \frac16\cdot\frac14 = \frac{1}{24}.$$

**检验:** 用"两对棱"公式复核. $BD \perp AC$ (前者沿 $x$ 轴, 后者沿 $z$ 方向), 两异面直线距离为点 $M$ 到直线 $AC$ 的距离, 即 $\dfrac{\sqrt2}{4}$; 于是 $V = \dfrac16\cdot\left|BD\right|\cdot\left|AC\right|\cdot d = \dfrac16\cdot\dfrac{\sqrt2}{2}\cdot 1\cdot\dfrac{\sqrt2}{4} = \dfrac{1}{24}$, 一致.

**点评:** 三个角条件的用途是给出两个方程: 顶点 $B$ 的条件给出 $\alpha = 180^\circ - \gamma-\psi$, 顶点 $C$ 的条件给出 $2\theta + \angle BCD = 90^\circ$; 把这两个关系与正弦定理结合就得到 $\tan\psi = \tan\gamma + 2$. 面角之和为 $180^\circ$ 并不意味着三面角退化 (球形三角形的周长为 $\pi$ 完全可能), 这是本题最容易误判之处.

#### 第 8 题

**答案:** $\dfrac{7}{78}$.

**问题陈述:** $S$ 由所有不超过 $2^{40}$ 且二进制表示中恰有两个 $1$ 的正整数组成, 从中随机取一个, 求能被 9 整除的概率.

**解答:** 第一步确定 $|S|$. 若 $n \le 2^{40}$ 的二进制恰有两个 $1$, 则 $n = 2^i + 2^j$ 且 $0 \le i < j \le 39$: 第 $40$ 位不能取, 因为取第 $40$ 位后 $n \ge 2^{40}$, 而 $n = 2^{40}$ 只有一个 $1$, 它的二进制中只有一个 $1$. 故

$$|S| = \binom{40}{2} = 780.$$

第二步数能被 $9$ 整除者. $2$ 模 $9$ 的幂以 $6$ 为周期:

$$\begin{array}{c|cccccc} i \bmod 6 & 0 & 1 & 2 & 3 & 4 & 5 \\ \hline 2^i \bmod 9 & 1 & 2 & 4 & 8 & 7 & 5 \end{array}$$

(因 $2^6 = 64 \equiv 1$). 要求 $2^i + 2^j \equiv 0 \pmod 9$, 即两个余数之和为 $9$. 在余数集 $\{1,2,4,8,7,5\}$ 中配对得

$$(1,8),\quad (2,7),\quad (4,5),$$

即 $(i \bmod 6,\ j \bmod 6) \in \{(0,3),(1,4),(2,5)\}$.

第三步计数. 注意 $i < j$ 且两类余数相差 $3 \pmod 6$, 所以 $i<j$ 等价于"$i$ 所在的步长不大于 $j$ 所在的步长".

- 类型 $(0,3)$: $i \in \{0,6,12,18,24,30,36\}$ (7 个), $j \in \{3,9,15,21,27,33,39\}$ (7 个), $i = 6a < j = 6b+3$ 等价于 $a \le b$, 计数 $\sum\limits_{b=0}^{6}(b+1) = 28$.
- 类型 $(1,4)$: $i \in \{1,7,13,19,25,31,37\}$ (7 个), $j \in \{4,10,16,22,28,34\}$ (6 个, 因为 $6\cdot 6 + 4 = 40 > 39$), 条件 $6a+1 < 6b+4$ 等价于 $a \le b$, 计数 $\sum\limits_{b=0}^{5}(b+1) = 21$.
- 类型 $(2,5)$: $i \in \{2,8,14,20,26,32,38\}$ (7 个), $j \in \{5,11,17,23,29,35\}$ (6 个, 因为 $6\cdot 6+5 = 41 > 39$), 条件 $a \le b$, 计数 $\sum\limits_{b=0}^{5}(b+1) = 21$.

故有利数共 $28 + 21 + 21 = 70$, 所求概率

$$P = \frac{70}{780} = \frac{7}{78}.$$

**检验:** $\dfrac{7}{78} \approx 0.0897$, 与"随机整数被 9 整除的概率 $\dfrac19 \approx 0.111$"同量级而略小 (因为二进制两位全为 $1$ 的数模 $9$ 分布略有偏斜), 数值合理. 另外用 $n = 3$: 恰两个 $1$, $3 = 2^0 + 2^1$ 不能被 $9$ 整除; 上述余数表中 $(0,1)$ 确实不在允许的配对里.

**点评:** 三个易错点: (i) $2^{40}$ 本身只有一个 $1$, 不属于 $S$; (ii) $j$ 的上界是 $39$ 而不是 $40$, 类型 $(1,4)$ 与 $(2,5)$ 中 $j$ 的个数比 $i$ 少一个; (iii) 计数时必须用 $i<j$ 的条件, 而 $i<j$ 恰好等价于步长比较, 于是变成三角形计数.

#### 第 9 题 (16 分)

**问题陈述:** $t \in [0,\pi]$, $x, y \ge 0$, $x + y = t$,

$$S = \sin^2x + \sin^2y + \left(8\sin^2t + 2\right)\sin x\sin y,$$

$M(t)$, $N(t)$ 分别为 $S$ 的最大值与最小值, $g(t) = M(t) - N(t)$. 求 $g$ 的最大值及取到最大值的 $t$.

**解答:** 记 $k = 8\sin^2t + 2$, 则 $k \ge 2$. 用和差化积把 $S$ 写成只含 $x+y$ 与 $x-y$ 的形式:

$$\sin^2x + \sin^2y = 1 - \frac{\cos 2x + \cos 2y}{2} = 1 - \cos(x+y)\cos(x-y),$$

$$\sin x\sin y = \frac{\cos(x-y) - \cos(x+y)}{2}.$$

令

$$c = \cos t = \cos(x+y), \qquad d = \cos(x-y),$$

则

$$S = 1 - cd + \frac{k}{2}\left(d - c\right) = 1 - \frac{kc}{2} + d\left(\frac{k}{2} - c\right). \tag{1}$$

$x, y \ge 0$, $x + y = t \in [0,\pi]$ 时 $x - y \in [-t, t] \subseteq [-\pi,\pi]$. $\cos$ 在 $[0,\pi]$ 上单调递减, 故 $|x-y|$ 可取遍 $[0,t]$, 从而

$$d = \cos(x-y) \text{ 取遍 } \left[c,\ 1\right] \quad (\text{端点 } d = c \text{ 对应 } x = t, y = 0 \text{ 或反之};\ d = 1 \text{ 对应 } x = y = t/2).$$

所以问题化为: $S$ 是 $d$ 的一次函数, $d \in [c,1]$.

斜率 $\dfrac{k}{2} - c = 4\sin^2t + 1 - \cos t$. 把它按 $\cos t$ 分解:

$$4\sin^2t + 1 - \cos t = 4 - 4\cos^2t + 1 - \cos t = \left(1 - \cos t\right)\left(4\cos t + 5\right).$$

因 $\cos t \le 1$ 且 $4\cos t + 5 \ge 1 > 0$, 故斜率非负, 且当 $t \in (0,\pi]$ 时为正. 于是

- $S$ 在 $d = 1$ 取最大值: $M(t) = 1 - c + \dfrac{k}{2}(1 - c) = \left(1 - \cos t\right)\left(2 + 4\sin^2t\right)$;
- $S$ 在 $d = c$ 取最小值: $N(t) = 1 - c^2 + \dfrac{k}{2}(c - c) = 1 - \cos^2t = \sin^2t$.

(这两步也可以用直接代入验证: $x = y = t/2$ 时 $S = (2+k)\sin^2\dfrac t2 = \left(1-\cos t\right)\left(2+4\sin^2t\right)$; $y = 0$ 时 $S = \sin^2t$.)

因此

$$g(t) = \left(1 - \cos t\right)\left(2 + 4\sin^2t\right) - \sin^2t.$$

令 $s = \cos t \in [-1,1]$, $\sin^2t = 1 - s^2$:

$$g = (1-s)\left(2 + 4 - 4s^2\right) - \left(1 - s^2\right) = (1-s)\left(6 - 4s^2\right) - 1 + s^2.$$

展开: $(1-s)(6-4s^2) = 6 - 4s^2 - 6s + 4s^3$, 故

$$g(s) = 4s^3 - 3s^2 - 6s + 5.$$

求导:

$$g'(s) = 12s^2 - 6s - 6 = 6\left(2s^2 - s - 1\right) = 6(2s+1)(s-1).$$

在 $(-1,1)$ 内唯一驻点 $s = -\dfrac12$; $s < -\dfrac12$ 时 $g' > 0$, $-\dfrac12 < s < 1$ 时 $g' < 0$, 故 $s = -\dfrac12$ 是 $[-1,1]$ 上的最大值点. 计算

$$g\left(-\frac12\right) = 4\cdot\left(-\frac18\right) - 3\cdot\frac14 - 6\cdot\left(-\frac12\right) + 5 = -\frac12 - \frac34 + 3 + 5 = \frac{27}{4},$$

而端点 $g(-1) = -4 - 3 + 6 + 5 = 4$, $g(1) = 4 - 3 - 6 + 5 = 0$, 都更小.

所以 $g$ 的最大值为 $\dfrac{27}{4}$, 取到时 $\cos t = -\dfrac12$, 即 $t = \dfrac{2\pi}{3}$.

**验证:** $t = \dfrac{2\pi}{3}$ 时 $\cos t = -\dfrac12$, $\sin^2t = \dfrac34$, $k = 8\cdot\dfrac34 + 2 = 8$. 于是 $M = \left(1+\dfrac12\right)\left(2+3\right) = \dfrac{15}{2}$ (直接验证: $x=y=\dfrac{\pi}{3}$ 时 $S = \dfrac34+\dfrac34+8\cdot\dfrac34 = \dfrac{15}{2}$); $N = \dfrac34$ (直接验证: $x = \dfrac{2\pi}{3}$, $y=0$ 时 $S = \dfrac34$). 故 $g = \dfrac{15}{2} - \dfrac34 = \dfrac{27}{4}$, 符合.

**总结:** 本题的核心是把二元极值问题通过"和差化积 + 变量代换 $d = \cos(x-y)$"化为一次函数在区间上的极值, 从而避开复杂的求导. 单调性方向由斜率 $\left(1-\cos t\right)\left(4\cos t+5\right) \ge 0$ 判定, 这是全部推理的关键一步. 最后 $g$ 是 $\cos t$ 的三次多项式, 求导即可. 注意 $t = 0$ 时 $M = N = 0$ (退化), 三次多项式在 $s = 1$ 的零点 $g(1) = 0$ 与之对应, 这个自检说明计算无误.

#### 第 10 题 (20 分)

**问题陈述:** $\{a_n\}$ 是正项等差数列, $n \ge 2$. 证明

$$\prod\limits_{k=1}^{n}\left(1 + \frac{1}{a_k}\right) \le \left(1 + \frac{a_1 + a_n}{2a_1a_n}\right)^{n}.$$

**解答:** 记 $b_k = \dfrac{1}{a_k} > 0$. 右端的底数为

$$1 + \frac{a_1+a_n}{2a_1a_n} = 1 + \frac{1}{2}\left(\frac{1}{a_1} + \frac{1}{a_n}\right) = 1 + \frac{b_1 + b_n}{2}.$$

证明分两步.

**第一步 (AM-GM):** 对 $n$ 个正数 $1 + b_1, \dots, 1 + b_n$ 用 AM-GM:

$$\prod\limits_{k=1}^{n}\left(1 + \frac{1}{a_k}\right) = \prod\limits_{k=1}^{n}\left(1 + b_k\right) \le \left(\frac{1}{n}\sum\limits_{k=1}^{n}\left(1 + b_k\right)\right)^{n} = \left(1 + \frac{1}{n}\sum\limits_{k=1}^{n}\frac{1}{a_k}\right)^{n}. \tag{1}$$

于是只需证明

$$\frac{1}{n}\sum\limits_{k=1}^{n}\frac{1}{a_k} \le \frac{1}{2}\left(\frac{1}{a_1} + \frac{1}{a_n}\right). \tag{2}$$

**第二步 (凸性 + 梯形不等式):** 设公差为 $d$, $a_k = a_1 + (k-1)d$. 因所有项为正, 对实数 $u \in [1,n]$ 定义

$$f(u) = \frac{1}{a_1 + (u-1)d},$$

它在 $[1,n]$ 上有定义且

$$f''(u) = \frac{2d^2}{\left(a_1 + (u-1)d\right)^{3}} \ge 0,$$

故 $f$ 是 $[1,n]$ 上的凸函数 (当 $d = 0$ 时 $f$ 为常数, 结论显然).

**引理 (离散梯形不等式):** 若 $f$ 在 $[1,n]$ 上凸, 则

$$\frac{1}{n}\sum\limits_{k=1}^{n}f(k) \le \frac{f(1) + f(n)}{2}.$$

证明: 把 $k$ 与 $n+1-k$ 配对 (两数之和恒为 $n+1$). 对凸函数 $f$, 固定和 $s$ 时 $h \mapsto f(s-h) + f(s+h)$ 关于 $h \ge 0$ 单调不减, 因为其导数为 $f'(s+h) - f'(s-h) \ge 0$ ($f'$ 单调不减). 取 $s = \dfrac{n+1}{2}$ 与 $h = \left|k - \dfrac{n+1}{2}\right| \le \dfrac{n-1}{2}$, 得

$$f(k) + f(n+1-k) \le f(1) + f(n).$$

对 $k = 1,2,\dots,n$ 求和, 左边每个 $f(j)$ 恰好出现两次, 右边出现 $n$ 次, 即 $2\sum\limits_{k=1}^n f(k) \le n\left(f(1)+f(n)\right)$, 引理得证. ($n$ 为奇数时中间项 $k = \dfrac{n+1}{2}$ 与自己配对, 同样由上面的单调性取 $h = 0$ 与 $h = \dfrac{n-1}{2}$ 比较即得.)

引理取 $f(u) = \dfrac{1}{a_1 + (u-1)d}$ 即得 (2):

$$\frac{1}{n}\sum\limits_{k=1}^{n}\frac{1}{a_k} \le \frac{1}{2}\left(\frac{1}{a_1} + \frac{1}{a_n}\right) = \frac{a_1 + a_n}{2a_1a_n}.$$

**第三步 (合并):** 由 (1) 与 (2), 并注意 $t \mapsto t^n$ 在 $\mathbf R_{>0}$ 上单调递增:

$$\prod\limits_{k=1}^{n}\left(1 + \frac{1}{a_k}\right) \le \left(1 + \frac{1}{n}\sum\limits_{k=1}^{n}\frac{1}{a_k}\right)^{n} \le \left(1 + \frac{a_1+a_n}{2a_1a_n}\right)^{n}. \qquad \blacksquare$$

**等号条件:** 两处等号同时成立需 $b_1 = b_2 = \dots = b_n$ (AM-GM 取等) 且 $f$ 为常数, 即 $d = 0$, 也就是 $\{a_n\}$ 为常数列. 确实此时两边都等于 $\left(1 + \dfrac{1}{a_1}\right)^n$.

**检验:** 取 $a_k = k$, $n = 3$: 左边 $= 2\cdot\dfrac32\cdot\dfrac43 = 4$, 右边 $= \left(1 + \dfrac{1+3}{2\cdot1\cdot3}\right)^3 = \left(\dfrac53\right)^3 = \dfrac{125}{27} \approx 4.63$, 不等式成立且不取等, 符合 ($d \ne 0$).

**总结:** 本题是"逐项 AM-GM 化积为和, 再用凸性把倒数的平均控制为端点平均"的两段式结构. 第二段本质是函数 $u \mapsto \dfrac{1}{a_1+(u-1)d}$ 的凸性与梯形公式; 因为没有连续性, 我们用"配对大和"的初等技巧代替积分. 一般化的结论是: 对正项凸数列 $\{c_n\}$ 有 $\dfrac{1}{n}\sum\limits_{k=1}^n c_k \le \dfrac{c_1+c_n}{2}$, 而 $\left\{\dfrac{1}{a_n}\right\}$ 正是这样的数列.

#### 第 11 题 (20 分)

**问题陈述:** 椭圆 $\dfrac{x^2}{4} + \dfrac{y^2}{2} = 1$, 定点 $A(-1,0)$, $B(1,0)$, $C(3,0)$. 过 $C$ 的直线交椭圆于 $P$, $Q$ 两点 ($Q$ 在 $P$ 左侧), 直线 $AP$ 与 $BQ$ 交于 $R$. 求 $R$ 的轨迹.

**解答:** 椭圆即 $x^2 + 2y^2 = 4$. 过 $C(3,0)$ 的直线若垂直 ($x = 3$) 与椭圆无交点, 故设其方程为 $y = m(x-3)$, $m \ne 0$, 且与椭圆有两交点.

**第一步: 交点坐标的关系.** 代入得

$$x^2 + 2m^2(x-3)^2 = 4 \Longleftrightarrow \left(1+2m^2\right)x^2 - 12m^2x + 18m^2 - 4 = 0.$$

设 $P = \left(p, m(p-3)\right)$, $Q = \left(q, m(q-3)\right)$, $q < p$ 为两交点, 则

$$p + q = \frac{12m^2}{1+2m^2}, \qquad pq = \frac{18m^2 - 4}{1+2m^2}. \tag{1}$$

由 (1) 消去 $m^2$: 记 $S_1 = p+q$, $S_2 = pq$, 由 $S_1 = \dfrac{12m^2}{1+2m^2}$ 解出 $m^2 = \dfrac{S_1}{12 - 2S_1}$ (注意 $S_1 < 6$, 分母非零), 并注意此时 $1 + 2m^2 = \dfrac{12}{12-2S_1}$; 代入 $S_2$ 的表达式:

$$S_2 = \frac{18\cdot\dfrac{S_1}{12-2S_1} - 4}{\dfrac{12}{12-2S_1}} = \frac{18S_1 - 4\left(12 - 2S_1\right)}{12} = \frac{26S_1 - 48}{12} = \frac{13S_1 - 24}{6}.$$

即有线性关系

$$6pq = 13(p+q) - 24. \tag{2}$$

反之, 由 (2) 与 (3) 可回解出 $m^2 = \dfrac{p+q}{12-2(p+q)}$, 故只要 $p \ne q$, (2) 就等价于"$P$, $Q$ 是过 $C$ 的某条直线与椭圆的两个交点". 由 (2) 可解出

$$q = \frac{13p - 24}{6p - 13}. \tag{3}$$

注意 $p \ne 3$ ($C$ 在椭圆外), $6p - 13 \ne 0$.

**第二步: 求 $R$.** 直线 $AP$ 的斜率 $\dfrac{m(p-3)}{p+1}$, 直线 $BQ$ 的斜率 $\dfrac{m(q-3)}{q-1}$. 设 $R = (X,Y)$, 则

$$Y = m\cdot\frac{p-3}{p+1}\left(X+1\right) = m\cdot\frac{q-3}{q-1}\left(X - 1\right).$$

记 $\alpha = \dfrac{p-3}{p+1}$, $\beta = \dfrac{q-3}{q-1}$, 则 $\alpha(X+1) = \beta(X-1)$, 即

$$X = -\frac{\alpha + \beta}{\alpha - \beta}.$$

计算

$$\alpha + \beta = \frac{(p-3)(q-1) + (q-3)(p+1)}{(p+1)(q-1)} = \frac{2pq - 4p - 2q}{(p+1)(q-1)},$$

$$\alpha - \beta = \frac{(p-3)(q-1) - (q-3)(p+1)}{(p+1)(q-1)} = \frac{2p - 4q + 6}{(p+1)(q-1)}.$$

故

$$X = -\frac{pq - 2p - q}{p - 2q + 3}, \qquad X + 1 = \frac{(p+1)(3-q)}{p-2q+3},$$

最后一式因 $-pq + 3p - q + 3 = (p+1)(3-q)$. 于是

$$Y = m\cdot\frac{p-3}{p+1}\cdot\left(X+1\right) = m\cdot\frac{(p-3)(3-q)}{p-2q+3} = -\frac{m(p-3)(q-3)}{p-2q+3}.$$

**第三步: 代入 (3) 消去 $q$.** 记 $y_1 = m(p-3)$ (即 $P$ 的纵坐标). 由 (3):

$$q - 3 = \frac{13p - 24 - 3(6p-13)}{6p-13} = \frac{-5(p-3)}{6p-13},$$

$$p - 2q + 3 = \frac{(p+3)(6p-13) - 2(13p-24)}{6p-13} = \frac{6p^2 - 21p + 9}{6p-13} = \frac{3(2p-1)(p-3)}{6p-13},$$

由 (3), $pq = \dfrac{13p^2 - 24p}{6p-13}$, 于是

$$pq - 2p - q = \frac{13p^2 - 24p - (13p-24)}{6p-13} - 2p = \frac{13p^2 - 37p + 24 - 2p(6p-13)}{6p-13} = \frac{p^2 - 11p + 24}{6p-13} = \frac{(p-3)(p-8)}{6p-13}.$$

于是

$$X = -\frac{(p-3)(p-8)}{3(2p-1)(p-3)} = -\frac{p-8}{3(2p-1)}, \qquad Y = -\frac{y_1\cdot\dfrac{-5(p-3)}{6p-13}}{\dfrac{3(2p-1)(p-3)}{6p-13}} = \frac{5y_1}{3(2p-1)}.$$

**第四步: 消去参数.** 由 $X = \dfrac{8-p}{3(2p-1)}$ 解出

$$3X(2p-1) = 8 - p \Longrightarrow p(6X + 1) = 8 + 3X \Longrightarrow p = \frac{8+3X}{6X+1}, \qquad 2p - 1 = \frac{15}{6X+1}.$$

于是 $Y = \dfrac{5y_1}{3}\cdot\dfrac{6X+1}{15} = \dfrac{y_1\left(6X+1\right)}{9}$, 即 $y_1 = \dfrac{9Y}{6X+1}$. 代入 $P$ 在椭圆上的条件 $p^2 + 2y_1^2 = 4$:

$$\left(\frac{8+3X}{6X+1}\right)^2 + 2\left(\frac{9Y}{6X+1}\right)^2 = 4.$$

乘以 $(6X+1)^2$:

$$(8+3X)^2 + 162Y^2 = 4(6X+1)^2 \Longrightarrow 64 + 48X + 9X^2 + 162Y^2 = 144X^2 + 48X + 4.$$

一次项抵消, 化简得 $-135X^2 + 162Y^2 + 60 = 0$, 除以 $-3$ 得

$$45X^2 - 54Y^2 = 20, \quad \text{即} \quad \frac{X^2}{4/9} - \frac{Y^2}{10/27} = 1.$$

**第五步: 确定轨迹的范围.** 参数 $m^2$ 的范围: 直线与椭圆有两个交点需判别式正, 即

$$m^2 < \frac25.$$

$m^2 \to 0^+$ 时 $p \to 2$ (此时 $Q \to -2$, 即弦趋于长轴); $m^2 \to \dfrac25$ 时 $P \to Q$ (切线), $p \to \dfrac43$. 由 $X = \dfrac{8-p}{3(2p-1)}$ 关于 $p$ 单调递减 ($\dfrac{dX}{dp} = \dfrac{-15}{3(2p-1)^2} < 0$), 得

$$p \in \left(\frac43,\ 2\right) \Longleftrightarrow X \in \left(\frac23,\ \frac43\right).$$

于是轨迹是双曲线 $45x^2 - 54y^2 = 20$ 上满足 $\dfrac23 < x < \dfrac43$ 的两段弧 (关于 $x$ 轴对称), 端点为

$$\left(\frac23, 0\right) \text{ (顶点, 由 } m \to 0 \text{ 得到)},\qquad \left(\frac43, \pm\frac{\sqrt{10}}{3}\right) \text{ (切线的极限位置, 不取到)}.$$

**检验:** 取 $m = 0$ 的极限情形 (弦为长轴): $P(2,0)$, $Q(-2,0)$, 极限点 $R = \left(\dfrac23, 0\right)$, 满足 $45\cdot\dfrac49 = 20$ ✓. 取 $m^2 = \dfrac15$: 由 (1) $p+q = \dfrac{12}{7}$, $pq = -\dfrac27$, 解得 $p = \dfrac{6+5\sqrt2}{7} \approx 1.868$, $q \approx -0.153$, $m = \dfrac{1}{\sqrt5}$, $y_1 = m(p-3) \approx -0.506$; 代入 $X = -\dfrac{p-8}{3(2p-1)} \approx 0.748$, $Y = \dfrac{5y_1}{3(2p-1)} \approx -0.309$, 而 $45X^2 - 54Y^2 \approx 25.16 - 5.15 = 20.01$, 符合.

**总结:** 这是一道"轨迹"与"射影对应"结合的问题: 由 $C$ 出发的直线在椭圆上诱导一个对合 $P \leftrightarrow Q$, 而 $R = AP \cap BQ$ 是分别以 $A$, $B$ 为中心的投影线束的对应点之交, 由 Chasles 定理它与锥线的对应必为一条二次曲线; 直接计算得到双曲线 (它一般不过 $A$, $B$, 因为对应不是从 $A$, $B$ 到同一点的透视). 关键技巧是把 $P$ 在椭圆上这一条件作为最后的约束, 前面全部用 $p$, $q$ 的对称式与弦关系 (2) 做消元. 注意轨迹是双曲线的两段弧而不是整支.

## 第二试

#### 第 1 题 (40 分, 平面几何)

**问题陈述:** $\odot O_1$ 与 $\odot O_2$ 交于 $A$, $B$. 过 $A$ 的直线分别与两圆再交于 $Y$, $Z$; 两圆在 $Y$, $Z$ 处的切线交于 $X$. 设 $\triangle O_1O_2B$ 的外接圆为 $\odot O$ (半径 $R$), 直线 $XB$ 交 $\odot O$ 于另一点 $Q$. 求证: $\left|XQ\right| = 2R$.

**解答:** 设 $\omega_1, \omega_2$ 的半径为 $r_1, r_2$.

**第一步: 坐标规范化.** 线段 $O_1O_2$ 是公共弦 $AB$ 的垂直平分线, 故 $O_1, O_2$ 在 $AB$ 的垂直平分线上. 不妨设

$$A\left(-1,0\right), \quad B\left(1,0\right), \quad O_1\left(0,u\right), \quad O_2\left(0,v\right), \quad u \ne v .$$

(令 $AB = 2$, 坐标的平移旋转缩放都不影响结论.) 于是

$$\omega_1: x^2 + y^2 - 2uy = 1, \qquad \omega_2: x^2 + y^2 - 2vy = 1, \qquad r_1^2 = 1 + u^2, \quad r_2^2 = 1+v^2.$$

**第二步: 求 $O$ 与 $R$.** 记 $w = u+v$. $\odot O$ 过 $O_1$, $O_2$, $B$. 由于 $O_1O_2$ 是竖直线, $O$ 在直线 $y = \dfrac{w}{2}$ 上. 设 $O = \left(\xi, \dfrac{w}{2}\right)$, 由 $\left|OB\right|^2 = \left|OO_1\right|^2$:

$$\left(\xi - 1\right)^2 + \frac{w^2}{4} = \xi^2 + \frac{(u-v)^2}{4} \Longrightarrow -2\xi + 1 + \frac{w^2 - (u-v)^2}{4} = 0 \Longrightarrow \xi = \frac{1+uv}{2}.$$

故

$$O\left(\frac{1+uv}{2},\ \frac{u+v}{2}\right), \qquad R^2 = \left|OB\right|^2 = \frac{(uv-1)^2 + (u+v)^2}{4} = \frac{(1+u^2)(1+v^2)}{4}. \tag{1}$$

顺带得到有用的关系 $R = \dfrac{r_1r_2}{AB}$ (这里 $AB = 2$).

**第三步: 由切线方程解出 $X$.** 过 $A$ 的直线设为 $y = k(x+1)$, 其中 $k$ 为斜率 (竖直线 $x = -1$ 情形可由 $k \to \infty$ 的极限得到). 直线上的点为 $(-1+\lambda, k\lambda)$, 代入 $\omega_1$:

$$\lambda^2\left(1+k^2\right) - 2\lambda\left(1+uk\right) = 0 \Longrightarrow \lambda_Y = \frac{2(1+uk)}{1+k^2},$$

同理 $\lambda_Z = \dfrac{2(1+vk)}{1+k^2}$. 于是 $Y = \left(-1+\lambda_Y, k\lambda_Y\right)$, $Z = \left(-1+\lambda_Z, k\lambda_Z\right)$.

$\omega_1$ 在 $Y$ 处的切线为 $x\,x_Y + y\,y_Y - u\left(y + y_Y\right) = 1$. 代入 $x_Y = -1+\lambda_Y$, $y_Y = k\lambda_Y$, 并乘以 $1+k^2$, 得一条关于 $X = (x,y)$ 的线性方程; 对 $\omega_2$ 在 $Z$ 处同法得第二条. 两方程为

$$\left(1+2uk-k^2\right)x + \left(2k+uk^2-u\right)y = 1+k^2+2uk+2u^2k^2, \tag{2}$$

$$\left(1+2vk-k^2\right)x + \left(2k+vk^2-v\right)y = 1+k^2+2vk+2v^2k^2. \tag{3}$$

(2) 减 (3) 消去含 $u^2, v^2$ 的项, 再除以 $(u-v)$ 得

$$2kx + \left(k^2-1\right)y = 2k\left(1+kw\right), \qquad w = u+v. \tag{4}$$

(2)(4) 联立解出 $X$; 系数行列式为

$$\left(1+2uk-k^2\right)\left(k^2-1\right) - 2k\left(2k+uk^2-u\right) = -\left(1+k^2\right)^2,$$

代入化简得

$$x = \frac{(2uv-1)k^4 + 4wk^3 + (4-2uv)k^2 + 1}{\left(1+k^2\right)^2}, \qquad y = \frac{2wk^4 + 4(1-uv)k^3 - 2wk^2}{\left(1+k^2\right)^2}. \tag{5}$$

(可以用 (4) 回代检验 (5): 把 (5) 代入 (4) 左边, 分子化为 $2k(1+kw)(1+k^2)^2$, 恰好吻合.)

**第四步: 用复数乘法把 $\overrightarrow{BX}$ 分解.** 记 $\sigma = uv$, $w = u+v$, 把向量用复数表示:

$$z := (x-1) + \mathrm iy = \frac{2k^2}{\left(1+k^2\right)^2}\left[(\sigma-1)(k^2-1) + 2wk\right] + \mathrm i\,\frac{2k^2}{\left(1+k^2\right)^2}\left[w(k^2-1) + 2(1-\sigma)k\right].$$

注意到

$$2wk - 2\mathrm i\left(\sigma-1\right)k = 2k\left[w - \mathrm i\left(\sigma-1\right)\right] = -2k\mathrm i\left[\left(\sigma-1\right) + \mathrm iw\right],$$

所以

$$z = \frac{2k^2}{\left(1+k^2\right)^2}\left[\left(\sigma-1\right)+\mathrm iw\right]\left[\left(k^2-1\right) - 2k\mathrm i\right]. \tag{6}$$

另一方面

$$\overrightarrow{BO} = O - B = \left(\frac{\sigma-1}{2},\ \frac{w}{2}\right) \ \longleftrightarrow\ \zeta := \frac{\left(\sigma-1\right)+\mathrm iw}{2}. \tag{7}$$

由 (1), $\left|\zeta\right|^2 = \dfrac{(\sigma-1)^2+w^2}{4} = \dfrac{(1+u^2)(1+v^2)}{4} = R^2$, 即 $\left|\zeta\right| = R = \left|BO\right|$.

**第五步: 读出两个关键等式.** 由 (6)(7), 复数的模与辐角给出

$$\left|XB\right| = \left|z\right| = \frac{2k^2}{\left(1+k^2\right)^2}\cdot R\cdot\sqrt{\left(k^2-1\right)^2 + 4k^2} = \frac{2k^2R\left(1+k^2\right)}{\left(1+k^2\right)^2} = \frac{4Rk^2}{1+k^2}, \tag{8}$$

(用到 $\left(k^2-1\right)^2 + 4k^2 = \left(k^2+1\right)^2$), 以及 $\overrightarrow{BX}$ 与 $\overrightarrow{BO}$ 的夹角满足

$$\cos\angle OBX = \frac{k^2-1}{\sqrt{\left(k^2-1\right)^2+4k^2}} = \frac{k^2-1}{k^2+1}. \tag{9}$$

**第六步: 算出 $\left|XQ\right|$.** 在 $\odot O$ 中弦 $BQ$ 满足 $\left|BQ\right| = 2R\cos\angle OBQ$ (当 $\cos\angle OBQ < 0$ 时按有向长度理解, 表示 $Q$ 落在 $B$ 的另一侧). 因 $X$, $B$, $Q$ 共线, 有向角 $\angle OBQ = \angle OBX$, 故沿 $\overrightarrow{BX}$ 方向的有向长度为

$$\overline{XQ} = \overline{XB} - \overline{BQ} = \frac{4Rk^2}{1+k^2} - \frac{2R\left(k^2-1\right)}{k^2+1} = \frac{2R\left(2k^2 - k^2 + 1\right)}{1+k^2} = \frac{2R\left(k^2+1\right)}{1+k^2} = 2R.$$

因结果恒为正, 无需取绝对值, 于是 $\left|XQ\right| = 2R$, 即线段 $XQ$ 等于 $\odot O$ 的直径. $\blacksquare$

**注:** 当 $k^2 = 1$ 时 (9) 给出 $\cos\angle OBX = 0$, 此时 $\left|XB\right| = 2R$ 且 $XB$ 与 $\odot O$ 相切于 $B$, $Q$ 与 $B$ 重合, 结论仍成立; 题目要求 $Q$ 为"另一点", 故实际处于 $k^2 \ne 1$ 的情形.

**问题背景:** 本题属于"两圆与切线的枢轴 (pivot) 结构", 与 Miquel 定理, 根轴, 以及"三角形的密克尔圆心"一类结论同源. 几个标准事实构成其骨架: (i) 连心线垂直平分公共弦; (ii) 由切线—弦夹角定理可得 $B, X, Y, Z$ 共圆 (记作 $\omega$), 于是 $XX^{*}$ 为 $\omega$ 的直径时 ($X^{*}$ 为 $X$ 在 $\omega$ 上的对径点), 由 $\angle XYO_1 = \angle XZO_2 = 90^\circ$ 得 $Y, O_1, X^{*}$ 共线, $Z, O_2, X^{*}$ 共线, 这就把"两圆切线之交点"翻译成"某点对两圆中心的投影"; (iii) 公式 $R = \dfrac{r_1r_2}{AB}$ 说明 $\odot O$ 的半径只依赖两圆半径与公共弦长, 这是本题数值结构的来源. 该结构在数学竞赛中反复出现, 例如"两圆内公切线交点与公共弦的关系", "Apollonius 圆"与"圆心三角形"的相似关系等.

**可能推广:** 主要有三个方向.

1. 把结论中的"$XB$ 与 $\odot O$ 的第二交点"换成一般点: 由证明中的 (8)(9) 可见更强的结论 —— 以 $B$ 为原点, $\overrightarrow{BO}$ 为极轴时 $X$ 的极坐标满足 $\left|XB\right| = 2R\left(1 + \cos\angle OBX\right)$, 即 $X$ 恒在一条以 $B$ 为焦点的"心脏线型"曲线上运动; 当直线 $AYZ$ 转动时 $X$ 的轨迹是一条确定的圆锥曲线 (有理参数 $k$ 给出有理参数化), 而 $Q$ 的轨迹是 $\odot O$ 上的一段弧.

2. 把 $\triangle O_1O_2B$ 换成 $\triangle O_1O_2C$ ($C$ 为公共弦上任一点) 或换成三圆心三角形, 会得到同类等式 $\left|XQ\right| = \dfrac{2r_1r_2}{\left|AB\right|}$; 一般地, 对两球做同样构造可得球面版本的结论.

3. 若允许 $\omega_1$, $\omega_2$ 相切 ($A = B$), 取极限可得"切点处切线与两圆切线"的退化情形, 结论变为 $\left|XQ\right| = 2R$ 仍成立, 但 $\odot O$ 退化为过 $O_1, O_2$ 的直线上的圆.

#### 第 2 题 (40 分, 数论)

**问题陈述:** 对任意素数 $p \ge 7$, 存在正整数 $n$ 与不被 $p$ 整除的整数 $x_1,\dots,x_n$; $y_1,\dots,y_n$, 使

$$x_1^2+y_1^2 \equiv x_2^2, \quad x_2^2+y_2^2 \equiv x_3^2, \quad \dots,\quad x_n^2+y_n^2 \equiv x_{n+1}^2 \pmod p,$$

其中 $x_{n+1} = x_1$ (下标循环).

**解答:** 全部在同余意义下于 $\mathbf F_p$ 中讨论. 记 $Q$ 为 $\mathbf F_p^*$ 中二次剩余之集, $\left|Q\right| = \dfrac{p-1}{2}$.

**第一步: 化为比值问题.** 设 $a_i = x_i^2$, 则 $a_i \in Q$ 且条件为 $a_i + y_i^2 \equiv a_{i+1}$. 因 $a_{i+1} = a_i + y_i^2 = a_i\left(1 + \dfrac{y_i^2}{a_i}\right)$, 令 $r_i = \dfrac{a_{i+1}}{a_i} \in \mathbf F_p^*$, 则

$$y_i^2 = a_i\left(r_i - 1\right), \qquad a_{i+1} = a_ir_i .$$

由于 $a_i \in Q$, 条件"$y_i \not\equiv 0$ 且 $y_i^2$ 为平方"等价于

$$r_i \in Q \quad \text{且} \quad r_i - 1 \in Q \quad (r_i \ne 1). \tag{1}$$

又 $a_{n+1} = a_1$ 要求 $\prod\limits_{i=1}^{n} r_i = 1$. 因此只要找到 $r \in Q$ 使 $r - 1 \in Q$, 取 $n$ 为 $r$ 在 $\mathbf F_p^*$ 中的阶, 令 $r_1 = \dots = r_n = r$ 即可 ($r^n = 1$ 保证循环).

**第二步: 构造这样的 $r$.** 取 $t \in \mathbf F_p$ 满足

$$t \ne 0,\quad t \ne \pm1,\quad t^2 \ne -1 . \tag{2}$$

这样的 $t$ 存在: 禁忌值最多 $4$ 个 ($p \equiv 3 \pmod 4$ 时 $t^2 = -1$ 无解) 或 $5$ 个 ($p \equiv 1 \pmod 4$ 时 $t^2 = -1$ 恰有两解), 而 $p \ge 7$ 时 $\left|\mathbf F_p\right| \ge 7 > 5$.

令

$$c = \frac{t^2+1}{2t}, \qquad d = \frac{t^2-1}{2t} \quad \in \mathbf F_p .$$

则

$$c^2 - d^2 = \frac{\left(t^2+1\right)^2 - \left(t^2-1\right)^2}{4t^2} = \frac{4t^2}{4t^2} = 1. \tag{3}$$

且由 (2): $c \ne 0 \iff t^2 \ne -1$; $d \ne 0 \iff t^2 \ne 1$; 又 $c \ne \pm1$, 因为 $c = \pm1$ 会由 (3) 得 $d^2 = 0$, 与 $d \ne 0$ 矛盾. 特别地 $c \ne 1$, 故 $c$ 的阶 $n \ge 3$ (从而 $n \ge 1$).

**第三步: 写出显式解.** 令

$$n = \mathrm{ord}_{\mathbf F_p^*}(c), \qquad x_i = c^{\,i-1}, \quad y_i = d\,c^{\,i-1} \quad (i = 1, 2, \dots, n).$$

则 $x_i \ne 0$, $y_i \ne 0$ (因为 $c \ne 0$, $d \ne 0$), 且

$$x_i^2 + y_i^2 = c^{2i-2}\left(1 + d^2\right) = c^{2i-2}\cdot c^2 = c^{2i} = x_{i+1}^2 \quad (\text{由 (3)}),$$

最后一个等号对 $i = n$ 读出 $x_{n+1}^2 = c^{2n} = 1 = x_1^2$, 而且更强地 $x_{n+1} = c^n = 1 = x_1$, 循环闭合. 把 $\mathbf F_p$ 中的代表元取为 $\{0,1,\dots,p-1\}$ 即得题目要求的整数. $\blacksquare$

**验证 (取 $p = 7$):** $\mathbf F_7^*$ 的二次剩余为 $Q = \{1,2,4\}$. 取 $t = 2$: $c = \dfrac{5}{4} = 5\cdot 2 = 10 \equiv 3$, $d = \dfrac{3}{4} = 3\cdot 2 = 6 \equiv -1$. 检验 $c^2 - d^2 = 9 - 1 = 8 \equiv 1$ ✓. $c = 3$ 的阶为 $6$ ($3^2 = 2$, $3^3 = 6$, $3^6 = 1$), 故 $n = 6$; 但也可以直接取 $r = c^2 = 2 \in Q$, $r - 1 = 1 \in Q$, 阶为 $3$, 于是

$$x_i^2 = 1,\ 2,\ 4 \ (i = 1,2,3), \qquad y_i^2 = 1,\ 2,\ 4,$$

即 $1 + 1 = 2$, $2 + 2 = 4$, $4 + 4 = 8 \equiv 1$, 循环成立, 对应 $x = 1, 3, 2$; $y = 1, 3, 2$ (模 $7$). 与题目要求完全吻合.

**验证 ($p = 5$ 为何不行):** $Q = \{1,4\}$; $r = 1$ 时 $r - 1 = 0$; $r = 4$ 时 $r - 1 = 3 \notin Q$. 故 (1) 无解, 任意 $n$ 都不可能. 这说明条件 $p \ge 7$ 是必要的.

**问题背景:** 本题是"二次剩余图上的环路存在性"问题. 把 $\mathbf F_p^*$ 中的二次剩余作为顶点, 若 $b - a$ 是非零二次剩余就在 $a$, $b$ 间连边, 题目要求的就是这个有向图的非平凡有向圈 (且要求所有比值 $b/a$ 落在 $Q$ 中). 由于 $x^2 + y^2$ 型方程的解数可由特征和精确计算 (Gauss 和), "二次剩余图"的连通性与圈结构是解析数论中的经典课题; 本题的构造 $c^2 - d^2 = 1$ 实际上就是单位双曲线的有理参数化, 用圆锥曲线的有理点把"两个都是二次剩余"这一算术条件转化为"参数自由选取", 从而绕过特征和估计. 这一手法在竞赛中很常见, 例如用 $\left(\dfrac{t^2-1}{t^2+1}\right)^2 + \left(\dfrac{2t}{t^2+1}\right)^2 = 1$ 的圆参数化来构造同时为二次剩余的数组.

**可能推广:** 三个方向.

1. 把"平方和"改为"平方差"或"$x^2 - Dy^2$": 由 Pell 型方程 $u^2 - Dv^2 = 1$ 的参数化同样可以构造, 只需 $D$ 为二次剩余; 若 $D$ 为非剩余则需另作处理, 结论是否仍成立与 $p$ 的分解有关.

2. 控制圈的个数与长度: 本题的 $n$ 是 $c$ 的阶, 可以取到 $\dfrac{p-1}{2}$ 的许多因子; 一个自然问题是: 是否总能取到 $n = 3$ (即找 $r$ 使 $r^3 = 1$, $r \ne 1$)? 这要求 $3 \mid p-1$ 且 $\omega = \dfrac{-1+\sqrt{-3}}{2}$ 与其差 $\omega - 1$ 同时为二次剩余, 由三次剩余符号决定, 是一个更难的问题.

3. 高维推广: 对给定的 $k$, $\mathbf F_p$ 中所有 $k$ 元组能否排成环使 $x_i^{(1)2} + \dots + x_i^{(k)2} = x_{i+1}^{(1)2}$? 由 $k$ 元二次型的等距群 (正交群) 的传递性, 可以用正交群的参数化代替双曲线参数化, 结论应对 $p$ 足够大时成立, 但"足够大"的界需要特征和估计.

#### 第 3 题 (50 分, 数列)

**问题陈述:** 各项不小于 1 的数列 $\{a_n\}$ 满足 $a_1 = 1$, $a_2 = 1 + \dfrac{\sqrt2}{2}$,

$$\left(\frac{a_n}{a_{n+1}-1}\right)^2 + \left(\frac{a_n-1}{a_{n-1}}\right)^2 = 2 \qquad (n \ge 2).$$

求 (1) 通项; (2) $\lim\limits_{n\to\infty}\dfrac{a_n}{n}$.

**解答:**

**第一步: 猜出结构.** 记

$$u_n = \frac{a_n}{a_{n+1}-1}, \qquad v_n = \frac{a_n-1}{a_{n-1}},$$

则条件为 $u_n^2 + v_n^2 = 2$. 对 $n = 2$: $a_1 = 1$, $a_2 = 1+\dfrac{\sqrt2}{2}$, 故 $v_2 = \dfrac{a_2-1}{a_1} = \dfrac{\sqrt2}{2}$, $v_2^2 = \dfrac12$, $u_2^2 = \dfrac32$.

由此往下递推 (由条件解出 $a_{n+1}$, 因 $a_{n+1}\ge1$ 故取值唯一):

$$a_3 = 1 + \frac{a_2}{\sqrt{2 - v_2^2}} = 1 + \frac{1.70711}{1.22474} = 2.39385,$$

$$a_4 = 1 + \frac{a_3}{\sqrt{2 - \left(\frac{a_3-1}{a_2}\right)^2}} = 1 + \frac{2.39385}{1.15470} = 3.07313, \qquad a_5 = 3.74870, \quad a_6 = 4.42222 .$$

计算各 $v_n^2 = \left(\dfrac{a_n-1}{a_{n-1}}\right)^2$:

$$v_2^2 = \frac12, \qquad v_3^2 \approx 0.6667, \qquad v_4^2 \approx 0.7500, \qquad v_5^2 \approx 0.8000, \qquad v_6^2 \approx 0.8000 .$$

前四个值与 $\dfrac{n-1}{n}$ 完全吻合, 于是猜测

$$v_n^2 = \frac{n-1}{n}, \qquad u_n^2 = 2 - \frac{n-1}{n} = \frac{n+1}{n}. \tag{1}$$

**第二步: 验证猜测并求通项.** 设 $a_n = \dfrac{A_n}{\sqrt n}$. 由 (1) 的第一个式子 ($a_n - 1 = a_{n-1}\sqrt{\dfrac{n-1}{n}}$):

$$\frac{A_n}{\sqrt n} - 1 = \frac{A_{n-1}}{\sqrt{n-1}}\cdot\frac{\sqrt{n-1}}{\sqrt n} = \frac{A_{n-1}}{\sqrt n} \Longrightarrow A_n = A_{n-1} + \sqrt n .$$

又 $A_1 = a_1\sqrt 1 = 1 = \sqrt1$, 故 $A_n = \sum\limits_{k=1}^{n}\sqrt k$, 即

$$a_n = \frac{1}{\sqrt n}\sum\limits_{k=1}^{n}\sqrt k = \frac{\sqrt1 + \sqrt2 + \cdots + \sqrt n}{\sqrt n}. \tag{2}$$

**第三步: 直接验证 (2) 满足全部条件.**

- $a_1 = \dfrac{\sqrt1}{\sqrt1} = 1$ ✓; $a_2 = \dfrac{1+\sqrt2}{\sqrt2} = 1 + \dfrac{\sqrt2}{2}$ ✓.
- $a_n \ge 1$: 因 $\sum\limits_{k=1}^n\sqrt k \ge \sqrt n$ ✓.
- 由 (2), $a_n - 1 = \dfrac{A_n - \sqrt n}{\sqrt n} = \dfrac{A_{n-1}}{\sqrt n}$, 故

$$v_n = \frac{a_n - 1}{a_{n-1}} = \frac{A_{n-1}/\sqrt n}{A_{n-1}/\sqrt{n-1}} = \sqrt{\frac{n-1}{n}};$$

- 又 $a_{n+1} - 1 = \dfrac{A_n}{\sqrt{n+1}}$, 故

$$u_n = \frac{a_n}{a_{n+1}-1} = \frac{A_n/\sqrt n}{A_n/\sqrt{n+1}} = \sqrt{\frac{n+1}{n}};$$

- 于是 $u_n^2 + v_n^2 = \dfrac{n+1}{n} + \dfrac{n-1}{n} = 2$ ✓.

由于条件式可唯一确定 $a_{n+1} = 1 + \dfrac{a_n}{\sqrt{2 - v_n^2}}$ (要求 $a_{n+1}\ge 1$, 且分母 $\sqrt{2 - v_n^2} > 0$), 满足条件的数列唯一, 故 (2) 就是所求通项.

**第四步: 求极限.** 由 $\sqrt k = \dfrac{2}{3}\left(k^{3/2} - (k-1)^{3/2}\right) + O\left(k^{-1/2}\right)$ 可有

$$\sum\limits_{k=1}^{n}\sqrt k = \frac23 n^{3/2}\left(1 + o(1)\right),$$

(标准估计: $\int_1^n \sqrt{x}\,\mathrm dx \le \sum\limits_{k=1}^n \sqrt k \le \int_1^{n+1}\sqrt x\,\mathrm dx + 1$, 两端都等于 $\dfrac23n^{3/2}(1+o(1))$). 于是

$$\frac{a_n}{n} = \frac{1}{n\sqrt n}\sum\limits_{k=1}^{n}\sqrt k = \frac{1}{n\sqrt n}\cdot\frac23n^{3/2}\left(1+o(1)\right) \longrightarrow \frac23 .$$

所以

$$a_n = \frac{1}{\sqrt n}\sum\limits_{k=1}^{n}\sqrt k, \qquad \lim\limits_{n\to\infty}\frac{a_n}{n} = \frac23 .$$

**检验:** $n = 2$ 时 (2) 给出 $\dfrac{1+\sqrt2}{\sqrt2} = 1 + \dfrac{\sqrt2}{2}$ ✓, 与初值一致; 刚才的递推数值 $a_3 \approx 2.3939$, $a_4 \approx 3.0731$ 也与 (2) 算出的

$$a_3 = \frac{1+\sqrt2+\sqrt3}{\sqrt3} \approx 2.3938, \qquad a_4 = \frac{1+\sqrt2+\sqrt3+2}{2} \approx 3.0731$$

吻合. 另外由 $\sum\limits_{k=1}^{n}\sqrt k = \dfrac23n^{3/2} + \dfrac12 n^{1/2} + O(1)$ 知

$$\frac{a_n}{n} = \frac23 + \frac{1}{2n} + O\left(n^{-3/2}\right),$$

故 $\dfrac{a_{100}}{100} \approx \dfrac23 + 0.005 \approx 0.6715$, 略大于 $\dfrac23$, 偏差量级 $n^{-1}$ 与估计一致 (收敛确实很慢).

**问题背景:** 这类递推来自"勾股型"恒等式: 条件 $u_n^2 + v_n^2 = 2$ 可以看成 $(u_n, v_n)$ 落在圆 $u^2+v^2 = 2$ 上, 而这个圆的参数化解正是 $u = \sqrt{\dfrac{n+1}{n}}$, $v = \sqrt{\dfrac{n-1}{n}}$ 所对应的 $\dfrac{n+1}{n} + \dfrac{n-1}{n} = 2$. 换言之, 递推的"不变曲线"是这条圆, 数列被这条曲线上的一个离散轨道决定. 被积型估计 (积分比较法) 与 Cesàro 型极限的结合是处理"前 $n$ 项平方根和"的标准手段, 与 Stolz 定理的思路一致.

**可能推广:** 四个方面.

1. 把 $2$ 换成 $2\beta$ ($\beta>0$): 此时取 $u_n^2 = \dfrac{\beta(n+1)}{n}$, $v_n^2 = \dfrac{\beta(n-1)}{n}$, 仍有 $u_n^2+v_n^2 = 2\beta$, 得 $A_n = A_{n-1} + \sqrt{\beta n}$, 于是 $a_n \sim \dfrac{2\sqrt\beta}{3}n$, 极限为 $\dfrac{2\sqrt\beta}{3}$. 若右端换成非常数列 $2c_n$, 则递推应读作 $a_{n+1} = 1 + \dfrac{a_n}{\sqrt{2c_n - v_n^2}}$, 通项不再有显式公式, 但极限仍可用逐项估计 (积分比较法) 求出.

2. 把指数 $1/2$ 换成一般 $\alpha \in (0,2)$: 设 $a_n = \dfrac{A_n}{n^{\alpha}}$ 型, 由类似推导得 $A_n = A_{n-1} + n^{\alpha}$, 从而 $a_n \sim \dfrac{n^{\alpha}}{\alpha+1}$, 极限 $\dfrac{1}{\alpha+1}$; 本题 $\alpha = \dfrac12$ 给出 $\dfrac23$.

3. 三项递推 $u_n^2 + v_n^2 + w_n^2 = 3$: 取 $u_n^2 = \dfrac{n+1}{n}$, $v_n^2 = 1$, $w_n^2 = \dfrac{n-1}{n}$ 即满足条件, 同样得 $A_n = A_{n-1}+\sqrt n$, 极限仍为 $\dfrac23$; 可见极限只由增长项 $\sqrt n$ 与分母幂次 $n^{1/2}$ 的比决定, 与递推中的项数无关.

4. 若把 $\left(\dfrac{a_n}{a_{n+1}-1}\right)^2 + \left(\dfrac{a_n-1}{a_{n-1}}\right)^2 = 2$ 中的分子分母位置互换 (例如 $\dfrac{a_{n+1}-1}{a_n}$), 则得到另一族"乘积型"递推, 极限由乘积 $\prod\limits_{k=1}^{n}\left(1 + \dfrac{1}{\sqrt k}\right)$ 的渐近行为决定, 与 $\mathrm e^{2\sqrt n}$ 型增长有关.

#### 第 4 题 (50 分, 组合)

**问题陈述:** $A_1, \dots, A_n$ 是有限集 $X$ 的非空子集, 且对任意 $1 \le i \le j \le n$, $A_i \cap A_j$ 不是单元集. 证明: 可把 $X$ 的元素分成两类, 使每个 $A_i$ 的元素不全在同一类中.

**解答:** 用"局部搜索 (max-count)"思想. 把"把 $X$ 分为两类"理解为给每个元素 $x$ 染上颜色 $\chi(x) \in \{1, 2\}$, 即 $\chi \in \{1,2\}^{X}$.

**第一步: 取最优染色.** 在全部 $2^{\left|X\right|}$ 种染色中, 选一个使"非单色集"个数

$$F(\chi) = \#\left\{i : A_i \text{ 中两种颜色都出现}\right\}$$

达到最大的 $\chi$. 只需证明 $F(\chi) = n$, 即没有 $A_i$ 是单色的.

**反设:** 存在 $k$ 使 $A_k$ 单色. 不妨设 $A_k$ 的元素全为颜色 $1$.

注意由 $i = j$ 的条件知 $\left|A_k\right| \ge 2$ (因 $A_k \cap A_k = A_k$ 不是单元集, 也不是空集).

**第二步: 逐个翻转, 得到"唯一色元"集.** 取任意 $y \in A_k$, 把 $y$ 的颜色由 $1$ 改为 $2$, 其余不变, 得新染色 $\chi_y$. 分析 $F$ 的变化:

- $A_k$ 现在含颜色 $2$ 的 $y$ 与颜色 $1$ 的其他元素 (因 $\left|A_k\right| \ge 2$), 故 $A_k$ 变成非单色, $F$ 至少 $+1$;
- 不含 $y$ 的 $A_i$ 的染色不变, $F$ 的贡献不变;
- 含 $y$ 的 $A_i$: 若它原含某颜色 $2$ 的元素, 则翻转后仍非单色 (贡献不变, 或从"单色 $1$"变"非单色", 是 $+1$); 若它原来是"除 $y$ 外全为颜色 $2$"的集合, 则翻转后整个变成单色 $2$, $F$ 减少 $1$;
- 含 $y$ 且原来全部颜色 $1$ 的集合: 翻转后非单色, 是 $+1$ 而不是 $-1$.

由 $\chi$ 的最优性, $F(\chi_y) \le F(\chi)$, 而 $A_k$ 已贡献 $+1$, 故必有某个 $A_i$ 由非单色变为单色. 由上段分析, 这种"变单色"的集合只能是这样: 它含 $y$, 且除 $y$ 之外的元素全是颜色 $2$ (于是 $y$ 是它唯一的颜色 $1$ 元素). 记其中一个为 $A_{\varphi(y)}$, 于是

$$\text{对每个 } y \in A_k, \ \exists\, \varphi(y): \quad y \in A_{\varphi(y)},\ \ \text{且 } y \text{ 是 } A_{\varphi(y)} \text{ 中唯一的颜色 1 元素}. \tag{1}$$

**第三步: 导出与条件矛盾.** $\varphi(y) \ne k$, 因为 $A_k$ 全为颜色 $1$ 而 $\left|A_k\right| \ge 2$, 不可能只有一个颜色 $1$ 元素.

取定 $y \in A_k$. 由 (1), $A_{\varphi(y)}$ 中除 $y$ 外都是颜色 $2$. 考虑交

$$A_{\varphi(y)} \cap A_k .$$

它含 $y$. 若它还含别的元素 $z \in A_k$, $z \ne y$, 则 $z \in A_{\varphi(y)}$ 且 $z$ 是颜色 $1$ (因 $A_k$ 全为颜色 $1$), 这与"$y$ 是 $A_{\varphi(y)}$ 中唯一的颜色 $1$ 元素"矛盾. 故

$$A_{\varphi(y)} \cap A_k = \{y\},$$

即 $A_{\varphi(y)}$ 与 $A_k$ 的交是单元集, 与题设"任意两子集之交不是单元集"矛盾.

矛盾说明反设不成立, 即最优染色下每个 $A_i$ 都含两种颜色. 这就给出了所需的两分类. $\blacksquare$

**注:** 证明中只用到 $i \ne j$ 时 $\left|A_i\cap A_j\right| \ne 1$ 以及 $\left|A_i\right|\ge 2$ 这两个条件, 而 $\left|A_i\right|\ge2$ 正是 $i = j$ 时的结论, 可见题设的条件形式虽包含 $i = j$, 其实是一致的设计.

**验证 (小例子):** $X = \{1,2,3,4\}$, $A_1 = \{1,2\}$, $A_2 = \{2,3\}$, $A_3 = \{1,3,4\}$, $A_4 = \{1,2,3,4\}$. 检查: $A_1\cap A_2 = \{2\}$ 是单元集, 违反条件, 故这组不允许. 换 $A_1 = \{1,2,3\}$, $A_2 = \{2,3,4\}$, $A_3 = \{1,4\}$: $A_1\cap A_2 = \{2,3\}$ ✓, $A_1\cap A_3 = \{1\}$ 违反. 可以看到凡是"两条集只交一点"的结构都被排除, 而排除之后总能染色, 例如 $A_1 = \{1,2,3\}$, $A_2=\{2,3,4\}$, $A_3 = \{1,2,4\}$ 时着色 $1\to1, 2\to 2, 3\to1, 4\to1$ 使三条集都非单色.

**问题背景:** 本题是超图二染色理论中 "Property B" 的一个特例. 一般问题是: 什么样的 $n$ 元子集族可以二染色使每个子集都非单色? Erdős 与 Lovász 的结果表明"线性"超图 (任意两边至多交一点) 若能保证最小边数增长得足够快则可二染色, 而 Fano 平面给出线性但不可二染色的反例. 本题的条件恰好相反 (任意两边不交于恰一点, 即交为空或至少两点), 这种"高重叠"结构使得局部搜索 (改变单个元素颜色) 就能奏效: 因为在单色块 $A_k$ 中任取一个元素翻转颜色, 若使 $A_k$ 变好就必须让另一个集合变坏, 而那个"变坏"的集合与 $A_k$ 只能交于被翻转的那一个点 —— 这正是被题设禁止的. 这种"最优染色 + 单点翻转"技巧在性质 B 的证明中反复出现 (例如证明最大度数约束下的二染色存在性).

**可能推广:** 三个层次.

1. 结论可以加强为"$\chi$ 的选取只需最大化 $\sum\limits_{i=1}^n \mathbf 1_{A_i \text{ 非单色}}$", 并且翻转论证只依赖局部信息, 因此可推广到"列表染色": 若每个元素可用的颜色不少于 $2$, 同样可保证每个 $A_i$ 非单色 (把最优性改为"非单色集合数最大"即得, 需要把单点翻转改为"换成另一个可用颜色", 论证相同).

2. 若把条件减弱为"任意两集合交不为单元集, 允许单元素集合", 则结论不成立 (取 $A_1 = \{x\}$, 无法使 $A_1$ 非单色), 说明 $\left|A_i\right|\ge2$ 不可去除.

3. 向 $k$ 染色推广: 若要求每个 $A_i$ 中出现至少两种颜色, 则 $k$ 染色下同样的局部搜索只给出"存在染色使每个 $A_i$ 不全同色", 与 $k$ 无关; 但若要求"每个 $A_i$ 中出现全部 $k$ 种颜色", 则需要更强的条件 (例如任意 $k$ 个集合的交不能太小), 这是"彩虹染色"型的开放性问题.

## 全卷总结

### 一, 考点分布

- 函数与方程 (第 1, 4, 5, 9 题): 奇偶性, 定义域对称性, 复系数方程的实根, 三角函数的恒等变形与最值.
- 三角 (第 2, 5, 9 题): 平方相加的技巧, 二倍角, 和差化积, 用一次函数处理"和为定值"的二元最值.
- 平面向量与几何 (第 3 题, 第二试第 1 题): 坐标法, 内积与夹角, 圆的切线, 密克尔型结构.
- 数列与不等式 (第 10 题, 第二试第 3 题): AM-GM, 离散凸性 (梯形不等式), 递推数列的通项与渐近.
- 组合计数 (第 6, 8 题, 第二试第 4 题): 不变量思想, 二进制与模 $9$ 的周期, 局部搜索与极值染色.
- 数论 (第二试第 2 题): 二次剩余, 单位双曲线的有理参数化, 乘法阶.
- 解析几何 (第 11 题): 弦的中点型对称式, 对合与轨迹, 双曲线的弧段.
- 立体几何 (第 7 题): 面角条件 (球形三角形周长), 对称构型下的三角求解, 体积公式与坐标验证.

### 二, 难度排序与易错点

由易到难大致为: 第 1, 5, 4, 6, 8, 2, 10, 9, 11, 第二试第 4, 第 3, 第 2, 第 1, 第 7 题.

主要易错点:

- 第 1 题: 忽略定义域对称性, 直接比较对数内部而漏掉 $b\ge1$.
- 第 2 题: 得出 $\sin(A+B) = \dfrac12$ 后不排除 $A + B = 30^\circ$, 丢掉一解.
- 第 3 题: 题面"任意一点"具有误导性; 必须验证夹角是否恒定, 本题答案并非常数.
- 第 4 题: 误以为 $r>0$, 从而丢掉 $r = -1$ 给出的 $m = 8$.
- 第 5 题: 用"判别式"处理二次函数在 $[-1,1]$ 上的正性, 忽略"开口向下时最小值在端点".
- 第 6 题: 试图讨论取法, 未看出"行号列号各成排列".
- 第 7 题: 误以为"面角之和为 $180^\circ$"迫使三面角退化; 实际上球形三角形周长可以等于 $\pi$.
- 第 8 题: $2^{40}$ 只有一个 $1$; $j$ 的上界是 $39$; $i<j$ 的计数必须用步长比较.
- 第 9 题: 忘记 $d$ 的取值范围是 $[c,1]$ 而非 $[-1,1]$.
- 第 10 题: 直接对 $a_k$ 用 AM-GM (错误), 必须先倒数再用凸性.
- 第 11 题: 只写双曲线方程而漏掉 "$x$ 的取值范围" 这一必要限制; 另外 $m = 0$ 时 $AP$ 与 $BQ$ 重合, $R$ 无定义, 需按极限处理.
- 第二试第 1 题: 若用综合法, 需先证 $B, X, Y, Z$ 共圆; 若用坐标法, 需注意 $\odot O$ 一般不过 $A$ (只有两圆正交时才过 $A$).
- 第二试第 2 题: 忘记验证 $p = 5$ 时无解, 从而看不出 $p\ge7$ 的必要性.
- 第二试第 4 题: 翻转论证中"变坏的集合"必须确实存在 (依赖最优性), 且必须用 $A_k$ 全为同色这一事实.

### 三, 可迁移的通用方法

1. **平方相加**: 形如 $a\sin X + b\cos Y = c$, $b\sin Y + a\cos X = d$ 的方程组, 平方相加必然产生 $\sin(X+Y)$, 是解三角形的标准起手式.

2. **和为定值的二元函数**: 出现 $x + y = t$ 时优先用
$$\sin^2x+\sin^2y = 1 - \cos t\cos(x-y), \qquad \sin x\sin y = \frac{\cos(x-y)-\cos t}{2},$$
把二元问题化为关于 $\cos(x-y)$ 的一次式, 再用端点取值; 这比暴力求导可靠得多.

3. **局部搜索 (max-count)**: 组合存在性证明中, 取"使目标函数最大"的染色, 再考虑单点翻转, 由最优性反推出结构约束. 第二试第 4 题是其典型, 也可用于列表染色, 性质 B 等.

4. **离散凸性与梯形不等式**: 对正项凸数列有 $\dfrac{1}{n}\sum\limits_{k=1}^n c_k \le \dfrac{c_1+c_n}{2}$, 配合 AM-GM 可把"积的不等式"化为"和的比较". 证明只需"同和配对, 凸函数使 $f(s-h)+f(s+h)$ 随 $h$ 增大"这一简单事实.

5. **把算术条件翻译成参数**: 第二试第 2 题用 $c^2-d^2=1$ 的参数化 $c = \dfrac{t^2+1}{2t}$, $d = \dfrac{t^2-1}{2t}$ 把"两个数同时为二次剩余"变成"$t$ 自由选取", 从而绕开深刻估计; 类似的圆参数化, Pell 参数化在数论构造题中效率极高.

6. **有理参数化 + 消元**: 第 11 题与第二试第 3 题都体现"用一个参数表示全部对象, 最后用一条几何 (或算术) 约束消去参数"的思想; 关键在于选择使关系成为线性或低次的那个参数 (第 11 题用交点横坐标 $p$, 第二试第 3 题用 $A_n$).

7. **坐标法处理"结论为长度关系"的几何题**: 第二试第 1 题的核心是把 $X$ 解出来后发现 $\overrightarrow{BX}$ 可以写成两个复数的乘积, 于是模与辐角同时读出 (即 $\left|XB\right|$ 与 $\cos\angle OBX$ 一并得到). 当综合法难以收尾时, 用复数乘法分解向量是高效技巧.

8. **自我检验的三种手段**: (i) 特殊值 (如第 8 题 $n=3$, 第 11 题 $m=0$); (ii) 极限与量级 (如第 9 题 $t\to0$, 第二试第 3 题 $n\to\infty$ 的 $\dfrac23$ 与数值 $\dfrac{a_{100}}{100}$ 相符); (iii) 反向构造验证 (如第 7 题把答案对应的四面体用坐标具体写出, 逐条核对 $BD$ 长, 三个面角和, 表面积与体积). 凡填空题, 至少用一种手段回代检查.
